# 社区行为规范

预见希望建立一个尊重创作者、欢迎初学者并重视实际反馈的社区。

参与 Issue、Discussion、Pull Request 或其他项目交流时，请遵守以下原则：

- 尊重不同经验、职业背景、创作方向和表达方式。
- 聚焦作品、流程和技术问题，不攻击个人。
- 欢迎初学者提问，不以是否会写代码衡量反馈价值。
- 讨论争议方案时提供具体场景和可验证依据。
- 未经许可，不公开他人的剧本、项目文件、客户资料或联系方式。
- 不发布骚扰、歧视、威胁、色情或明显与项目无关的内容。

维护者可以编辑、隐藏或删除违反规范的内容，并根据严重程度限制参与。遇到需要私下处理的问题，请使用仓库的安全报告渠道，避免在公开 Issue 中披露个人信息。
