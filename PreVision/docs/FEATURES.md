# 功能清单

本文档对应预见 PreVision v0.7.2 Preview。

0.7.2 已把离线分镜规划器 v2、语义代理模型库 MVP 和顶部捕获保存位置修复统一交付到 `~/Applications/PreVision.app`。语义代理的固定 App 入口、11 类类型与独立尺寸编辑已经验证，但这不代表 Seedance 实机多镜头生成一致性已经通过。

首次启动白马欢迎场景已进入开发预览和实时 Web 验收，但尚未写入上述固定 App。

## 场景编辑

- 添加、选择、移动、旋转和删除角色、道具、车辆、马匹与环境物件。
- 调整对象高度并一键贴地。
- 基础接触检测与防穿透。
- 人物与马匹骑乘绑定。
- 空白场景区域左键环绕观察、右键平移场景。
- 语义代理模型库 MVP：成人男性、成人女性、儿童、狗、SUV、树 A、树 B、石头、灌木、房屋体块和道路。
- 语义类型与尺寸分离：类型决定低复杂度轮廓、默认比例和稳定配色；宽/高/深可独立编辑、保存和重开恢复，允许“三米儿童”等非常规设定。
- 道路为地表型参考代理，不作为阻挡对象参与基础碰撞。

## 调度路径

- 为角色与道具建立多点运动路径。
- 直线和曲线两种连接方式。
- 在右侧属性栏增加、删除和切换路径点。
- 路径点高度、位置、到达时间和速度参数。
- 同一场景内同时显示多条独立路径。

## 摄影机

- 多机位点路径与平滑空间插值。
- 每个机位点独立记录位置、水平转角、俯仰角与 FOV。
- 自由朝向或锁定跟随角色。
- 点选机位快速监看。
- 从角色/道具路径复制同形摄影机路径，并自动偏移以便选择。
- 整条摄影机路径右键拖动，单点左键编辑。
- 主导演台用 48 CSS px 的无品牌专业电影摄影机显示当前机位与镜头方向；透明 27px 命中代理保留点选/拖动，monitor、摄影机画面、缩略图与 Seedance 导出不包含编辑辅助模型。

## 时间轴

- 摄影机、人物与道具分轨显示。
- 运动条整体平移，首尾手柄修改起止时间。
- 菱形关键帧逐点拖动。
- Shift 多选关键帧。
- `⌘C`、`⌘V`、Delete 与 `⌘Z`。
- 关键帧吸附、时间刻度缩放与播放头定位。
- 轨道独立时间与节点同步。
- 摄影机位置、朝向、焦距子轨道。
- 速度预设与贝塞尔曲线编辑。

## 光影与参考

- 方向太阳光：方位、高度、强度、色温。
- 实时投影、阴影柔和度与辅助线。
- 背景参考板和平面/全景显示方式。

## 离线分镜规划

- 解析单个场景、最多两名主要角色的中文或英文剧本；识别说话人对白、动作、环境、场景标题、括号动作和常见中英文标点。
- 使用与界面翻译分离的稳定离线词典和规则，相同文本、选项与场景人物重复分析得到相同 `StoryboardPlan`，不请求网络、Agent、云端模型或付费 AI。
- 在写入项目之前显示临时分析预览：推荐/手动模板、选择理由、置信度、角色映射、节拍覆盖与动态 4–8 镜。
- 可在预览中修正主要角色映射，并逐镜调整主体、时长和 FOV；原文或模板/情绪/节奏变化会使旧计划过期，必须重新分析。
- 分析窗口可用右下角手柄连续二维缩放，也可在标题栏切换应用内全屏/还原；标题、角色映射和底部操作保持可见，节拍/镜头列表独立使用剩余高度滚动。Esc 在全屏时先还原，再按既有语义取消。
- 每个有效节拍由镜头覆盖；超过八镜上限时，相邻节拍带明确合并理由。应用后仍使用 project v5 的场景、人物/对象和镜头字段，不保存瞬时分析元数据。
- 基础约束包含 180°轴线同侧、主次角色视线方向、锁定主体入画，以及有限机位、1–15 秒时长和 10–110° FOV。
- 当前不包含多场次批处理、三人以上复杂对白、复杂遮挡搜索、姿态/动作路径自动生成或电影级镜头优化。

## 项目与输出

- 真正首次启动（当前 origin/profile 没有 autosave）打开可直接编辑的白马骑手欢迎项目：四个镜头共 16.5 秒，包含白马调度路径、骑手挂载与侧向太阳。
- 有效 autosave 原样恢复；JSON/启动结构损坏或本地存储不可用时打开标准双人对话并显示警告，启动阶段不覆盖原 autosave。
- 用户主动 New Project 始终建立标准双人对话；清空浏览器站点数据后再次进入会重新被识别为首次启动。
- 本地自动保存与项目文件打开/保存。
- 镜头和整场景预演。
- 当前摄影机或应用画面截图；桌面端顶部入口先选择系统保存位置，取消不写文件。
- 当前摄影机或应用画面录屏；桌面端顶部入口先选择系统保存位置，取消不开始录制。
- 顶部显示成功捕获的完整保存路径与实际文件后缀。
- 镜头参考图、视频和结构化项目数据导出。
