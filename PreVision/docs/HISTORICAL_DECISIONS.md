# 历史决策

这里只记录能够在当前代码或测试中找到证据、且仍影响开发的决定。日期表示决定形成或被仓库证据确认的时间，不等同于发布日期。

## HD-001 离线优先、无云端依赖

- 状态：有效。
- 决定：核心导演台直接从本地 HTML 运行，外部 AI 生成服务不嵌入应用。
- 证据：内嵌 Three.js、本地 `vendor/`、浏览器下载回退和 Electron 本地文件桥。
- 影响：可低成本试用；协作、在线更新和遥测不在当前架构内。

## HD-002 项目 → 场景 → 镜头三级结构

- 状态：有效。
- 决定：项目包含多个场景，场景包含对象和多个镜头。
- 证据：项目数据 v5、场景栏、镜头条和序列化测试。

## HD-003 调度点只能在右栏增加/删除

- 状态：有效。
- 决定：画布拖动对象只改变当前位置，不再自动生成调度点；已有黄色点仍可直接拖动。
- 证据：调度路径面板文案和“右栏增删点 / 画布拖已有点”测试。
- 原因：避免误操作导致路径快速膨胀。

## HD-004 摄影机与对象路径保持独立

- 状态：有效。
- 决定：点击摄影机点只预览摄影机；点击对象点只覆盖该对象状态。时间关系通过显式模式建立，不用隐式全局绑定。
- 证据：`previewCamPt`、`previewActorPoints` 和独立预览测试。

## HD-005 当前默认同步语义是节点同步，可切换

- 状态：有效。
- 决定：兼容数据默认归一为 `pointSync`，同时保留 `arcLength` 和 `custom`；多轨可用对象联动模式。
- 证据：场景载入/保存归一逻辑、时间轴和节点同步测试。

## HD-006 复杂运镜逐点记录位置、朝向与焦距

- 状态：有效。
- 决定：摄影机不是必须始终看向主体；手动朝向时每个机位点保存 yaw、pitch 和 FOV，并独立平滑插值。
- 证据：`camKeys`、三条摄影机子轨道和复杂无人机运镜测试。

## HD-007 太阳使用方向光模型

- 状态：有效。
- 决定：用方向光近似太阳，提供方位、高度、色温、强度、环境补光和阴影质量。
- 证据：Three.js DirectionalLight 配置和太阳测试。
- 边界：用于预演真实光向，不是光线追踪渲染器。

## HD-008 工作区录屏不调用系统屏幕共享选择器

- 状态：有效。
- 决定：只录制 PreVision 应用内容时使用应用内 Canvas/html2canvas 合成，不包含浏览器地址栏或系统程序栏。
- 证据：`startWholePageRecording` 不使用 `getDisplayMedia` 的测试。

## HD-009 桌面端优先 macOS Apple Silicon

- 状态：有效。
- 决定：先稳定 Mac 版，暂停 Windows maker 和 Windows 发行。
- 证据：Forge 只配置 ZIP/DMG，桌面壳测试明确拒绝 MakerSquirrel。

## HD-010 右侧属性栏最多占窗口一半

- 状态：有效。
- 决定：右栏可拖宽，最大为窗口 50%，监视器随宽度实时重算。
- 证据：`RIGHTW_KEY` 和右栏拖拽测试。

## HD-011 时间轴在笔记本上可压缩

- 状态：有效。
- 决定：轨道面板高度可拖动并记忆；低于阈值进入紧凑模式；隐藏/改变高度自动重算主画布宽高比。
- 证据：`previz_motion_h`、ResizeObserver 测试和 1316×768 人工检查。

## HD-012 中文产品名改为“预见”

- 状态：有效。
- 决定：产品中文名统一为“预见”，英文名保留 PreVision。
- 证据：页面 title、Electron 菜单、导出路径、文档和当前项目目录。

## HD-013 开源方式尚未决定

- 状态：待决策。
- 决定：在许可证和品牌边界确认前，只建立本地 Git 工作流，不自动创建公开仓库。
- 证据：README 许可证说明、无 remote、未登录 GitHub。
