# 开发路线图

路线图表达方向，不代表固定发布日期。优先级会根据真实创作反馈调整。

## v0.8：把调度变得更直观

- 完善时间轴的框选、批量移动、缩放与吸附体验。
- 让速度曲线与空间路径编辑形成清晰的双向反馈。
- 增加轨道分组、锁定、隐藏与颜色管理。
- 支持更灵活的同步方式：按时间、按节点、按事件或完全独立。
- 强化项目恢复、自动备份和异常退出保护。

## v0.9：提升镜头与表演表达

- 摄影机运动和镜头朝向使用更稳定的电影级插值。
- 增加焦点距离、景深与更多镜头参数。
- 更细致的角色姿态、骑乘关系和道具挂接。
- 更可靠的碰撞体、地面接触和简单物理约束。
- 可保存和复用的运镜、灯光与场景预设。

## v1.0：可交付的导演工作流

- 稳定的 macOS 安装包与升级流程。
- 完整项目格式、版本迁移与兼容策略。
- 镜头清单、分镜参考、提示词与结构化数据统一导出。
- 面向主流 AI 视频工作流的适配与扩展接口。
- 中英文界面和完整用户手册。

## 未来探索

- Windows 桌面端。
- 可选 Web 体验版与反馈收集。
- ComfyUI 节点或其他工作流连接方式。
- 多人协作、镜头评审与批注。
