## 用户问题

用户确认采用 B「电影控制台」作为主界面、C「导演专注台」作为专注模式、B 的统一描边图标，并保留全部主题。

## 目标

- 把已确认的电影控制台视觉层级落地到真实应用，不改变现有功能信息架构。
- 建立统一的 B 风格描边 SVG 图标和全局/视口/对象三级菜单视觉。
- 左场景栏、右监视器/属性栏和底部时间轴具备一致、可恢复的展开/紧凑交互。
- 增加一键导演专注模式，在不改写既有栏位偏好的情况下最大化主视口。
- 保留石墨/深海夜间、雾白日间、暮光靛蓝、胶片琥珀主题；主题为本机偏好，不写入项目文件。
- 在 1316×768、1440×900、1728×1117 下保持主视口、监视器和时间轴可用。

## 非目标

- 不实现 Blender 式任意区域拆分、跨窗口停靠或插件化编辑器。
- 不新增材质、节点、内容浏览器等当前不存在的业务模块。
- 不改变摄影机数学、时间轴映射、路径数据、项目 v5、自动保存或媒体输出语义。
- 不拆分整个单文件应用，不引入 React/Vue、在线图标、在线字体或新运行时依赖。

## 风险

- 数据：主题/布局若误入 `project.settings` 会污染项目、历史栈和修改时间。
- UI/交互：面板过渡可能导致 renderer 宽高、射线拾取和时间轴几何短暂失真。
- 安全：新菜单不得扩大 preload/IPC 边界或加载在线资源。
- 发布：日间主题可能在 Electron 固定深色背景上启动闪黑；若修改主进程需升级 desktop/full 测试。

## 实施记录

- 假设：B 的模式轨只链接现有场景、摄影机、角色/道具、路径、光影区域，不新增业务模块。
- 关键决定：主题与布局使用独立本机偏好键；专注模式只叠加瞬时 CSS/状态，不覆盖用户固定栏宽与折叠偏好。
- 实际修改：重建 42px 全局命令栏、46px 左模式轨、场景抽屉、主视口工具栏、336px 属性/监视器栏与 46px 属性轨，增加底部状态栏与本地 SVG sprite；旧业务 DOM ID 保留。
- 实际修改：新增 `setUITheme`、`setLeftPanelState`、`setRightPanelState`、`setTimelineState`、`setDirectorFocus`、`closeUIMenus`；布局与主题只写独立本机 key，临时抽屉和导演专注不覆盖持久偏好。
- 实际修改：建立石墨深海、雾白日间、暮光靛蓝、胶片琥珀四套语义令牌；分离品牌、选中、调度、录制/危险色，不改 Three.js 世界色和路径数据。
- 实际修改：栏位与专注切换后统一重算主/监视器 renderer；工作区录屏背景从当前主题令牌读取。
- 实际修改：扩展 UI v3 VM 回归与 DOM/ResizeObserver/rAF 桩，增加四主题、栏位三态、专注恢复、菜单、可访问性、renderer 尺寸和项目隔离断言。
