## 用户问题

用户希望依次升级场景创作能力：精细化人物和道具、将马改为白色并让人物五官足以辨别头部朝向；在人物头部调整同一类别增加全身关节调整；增加可承载人物或骑马组合且不穿模的连绵起伏方形沙漠；将新建场景的四条导演路线替换为更常用的四种场景和构图形式；同步调整“剧本 → 分镜”可以调取和生成的内容。用户同时要求落实录屏中的导航意见：左栏按“项目下的场景 → 场景下的镜头”分层钻取，镜头缩略图和新增入口迁入左栏，底栏不再重复展示镜头条。

## 目标

- 保持当前程序化离线资产架构，提升人物、马匹及常用道具的形体、材质和方向辨识度。
- 人物头部具备明显且跟随头部关节旋转的五官；马匹主体为白色并保留骑乘、路径和贴地能力。
- 在既有人物调整类别中补齐主要肢体关节的可理解控制，并保证项目保存恢复。
- 新增一整块连绵起伏的方形沙漠环境，人物和骑乘组合放置后不得陷入地形。
- 以四种高频场景和构图模板替换当前导演路线，并使离线剧本分镜规则同步使用新内容。
- 左栏建立项目→场景→镜头的分层导航；镜头缩略图、新增、选择、删除和重命名迁入左栏，并保留返回项目场景列表的上一级入口。
- 底栏只保留播放控制、时码与调度轨道，移除重复镜头条和仅用于该镜头条的 `filmstrip` 状态；不删除红色“预演”、右侧监视器和播放本场景能力。
- 所有新增或修改的用户文案使用 language key，双语言资源保持一致。

## 非目标

- 不引入在线模型、付费 AI、外部素材下载或新的前端框架。
- 不把基础包围盒碰撞改造为完整刚体或骨骼物理系统。
- 不在本轮顺手重构单文件应用架构。
- 本任务按多轮快速开发预览推进；用户明确“定稿/正式更新”前不替换 `~/Applications/PreVision.app`。

## 风险

- 数据：新增关节、环境属性或模板若绕过现有序列化入口，会造成项目往返丢失或旧项目加载回退异常。
- UI/交互：关节控件数量增加可能挤压右栏；五官和精细几何在远景可能不可读或干扰选择。
- 安全：无新增网络、外部文件输入或 Electron IPC；继续遵守离线运行边界。
- 发布：程序化几何增加可能影响帧率和包体启动；预览阶段不得误替换固定 App。

## 实施记录

- 假设：“依次修改”表示五项属于同一完整任务，但每项先做开发预览，确认后再继续下一项。
- 关键决定：先实现资产优化和沙漠预览；用户随后要求插队补齐全身关节、四模板和剧本分镜同步，因此这些能力与左栏层级、底栏去重一并冻结在本任务提交中。
- 第 1 步实际修改：人物增加可随颈部旋转的眼睛、瞳孔、眉毛、鼻、嘴、耳朵和头发，并区分肤色、上衣、裤装与鞋；木箱增加护角、斜撑、把手和盖板，车辆增加格栅、尾灯和后视镜。
- 白马在用户反馈“仍太卡通”后进行了三轮轮廓重构：最终使用连续截面躯干而非球体拼接，增加肩胛/臀肌、抬高的双段锥形颈、收窄长脸、微型眼鼻、前后肢不同的解剖折线、小型关节与锥形马蹄；同时降低选中高亮对浅色毛发的染色。
- 用户近景检查发现口鼻下方存在游离零件；根因是长脸主体旋转后，口鼻、下颌、五官及衔具仍使用根组独立坐标。现已增加统一 `horseHeadRig` 并改为局部坐标，且用父子关系和包围盒相交断言防止再次脱离。
- 兼容性：保留 `horseLegs.FL/FR/BL/BR`、`seatY=1.5`、`seatZ=-0.05`、人物关节 key、对象种类和项目 schema；沙漠对象额外保存 `terrainVersion: 1`，以便后续地形算法升级时维持旧项目外观。
- 沙漠实现：环境库新增一整块 24m 方形连续起伏网格；运行时贴地直接对可见网格的实际三角面插值取高，对象会按足迹范围的最高支撑面调整 Y，确保人物和人骑马组合不陷入曲面。
- 动态贴地：人物/白马路径转向、程序化步态和人物姿态/关节调整完成后都会以最终脚掌或马蹄位置重新贴地；沙漠本身变换时也会更新静态对象和骑乘组合。
- 沙漠碰撞边界：`desert` 作为专用支撑地形排除于普通包围盒障碍，其他对象之间的现有接触防穿透语义保持不变；项目 schema 仍为 v5，只新增可往返的对象 `kind`。
- 国际化：触及的环境库标题、旧按钮、沙漠入口、说明和动态对象名全部迁移为 language key，`zh-CN` / `en-US` 同步。
- 层级导航：左栏项目层显示项目下的场景，点击场景后钻取到该场景的镜头缩略图列表，并提供返回项目场景入口；镜头新增、选择、删除、重命名均迁入左栏。动态名称用 DOM `textContent` 构造，避免用户内容被当作 HTML。
- 底栏去重：已移除 `#tltrack`、`#shotlist`、旧播放头及其拖拽逻辑，保留红色预演、前后镜、时码、调度轨道、右侧监视器和播放本场景；时间轴只保留 `full` / `hidden` 两态，旧 `filmstrip` 与 legacy 关闭偏好迁移到 `hidden`。
- 全身关节：人物骨架新增左右腕、左右踝枢轴，躯干支持弯曲和扭转；右栏同一“人物姿态与全身关节”区域提供头、躯干、左右肩肘腕和髋膝踝选择及对应单/双轴调节。数据继续复用 `joints`，旧项目缺少新 key 时回退为 0，不提升 schema。
- 四个模板：新建场景改为“双人对话·正反打、单人表演·景别递进、动作追逐·轴线连续、环境建立·空间交代”，每个模板均物化为四镜并保存稳定 `templateId`。
- 剧本分镜同步：弹窗可手动锁定上述四模板，或按对白、单人、动作、环境关键词自动路由；情绪和节奏只微调焦段、机位与时长，生成场景继续保存 `templateId` 和剧本文本。
- 开发预览：Electron 隔离数据目录中完成“新建场景 → 四模板 → 单人表演四镜”“选中人物 → 展开 16 项关节 → 左腕双轴调至 10°”“剧本自动模式 → 追逐文本 → 动作追逐四镜”的完整链路。另实际添加白马与方形沙漠、将人物挂载到马背，近景确认马蹄、地形和骑手鞍位接触正常；画布棋盘格/浅灰/深灰三态均可切换；左栏层级、底栏去重、红色预演、调度轨道和监视器均可见。固定 App 未更新。
