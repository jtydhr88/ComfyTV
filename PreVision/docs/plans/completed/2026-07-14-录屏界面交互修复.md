## 用户问题

依据用户约四分钟的实际操作录屏，修复左右模式按钮重复、原生工具提示延迟、右栏临时抽屉覆盖时间轴、右栏拖拽边界不明显、时间轴高度拖拽时导演区频闪等交互问题，并为导演场景地面增加棋盘格、纯白、纯黑及自定义外观。

## 目标

- 左侧模式轨只保留「场景与镜头」主入口以及底部时间轴/专注入口，移除与右侧摄影机、演员、路径、灯光完全重复的四个按钮。
- 模式轨图标在鼠标悬停或键盘聚焦时立即显示自定义文字提示，不再依赖延迟出现的浏览器原生 `title`。
- 新用户默认进入「固定右栏 + 完整时间轴」布局；右栏内容参与主工作区排版，时间轴右边缘止于右栏左边缘，不再先以覆盖式临时抽屉遮挡时间轴。
- 移除右栏内容中的固定/一键展开按钮；右侧快捷入口直接打开固定右栏，右栏宽度保持连续拖拽调节。
- 右栏分隔条提供与时间轴拖拽手柄一致的可发现性：悬停/聚焦时出现双向三角提示及高亮状态。
- 时间轴高度拖拽期间不触发导演区黑屏/频闪，并在拖拽结束后保持摄影机画幅、监视器画幅和播放头位置正确。
- 场景地面支持棋盘格、纯白、纯黑、自定义颜色和自定义图片纹理；旧项目缺少该字段时仍按棋盘格显示。

## 非目标

- 不调整摄影机路径、对象路径、关键帧时间、缓动、播放或项目导出业务语义。
- 不重构单文件应用或替换 Three.js。
- 不改变全景天空球、场景图板和现有背景图片导入的既有含义。
- 不建立公开 Web 部署，不发布安装包，不调用真实付费 AI 服务。

## 证据与现状

- 代码：左右四个入口均调用 `openInspector`；右栏 `peek` 为绝对定位覆盖层，`rightPin` 才切换到参与 flex 布局的 `expanded`；工具提示使用原生 `title`；时间轴拖动过程中反复调度 renderer 尺寸更新。
- Git：基线 `0925ef0`，包含 B「电影控制台」、C「导演专注」、四主题以及本机 App/网页入口刷新。
- 测试/运行：基线文档记录 `test:app` 302 项、`test:desktop` 20 项、`test:foundation` 45 项通过；本任务开始时工作树干净。
- 文档/历史线索：用户录屏 `2026-07-14 01.18.58` 已离线转写并逐段与画面核对；本验收单只保留业务结论，不提交私人录屏或本机路径。

## 风险

- 数据：自定义地面图片会增加项目/localStorage 体积；必须保留现有超配额降级和旧项目加载路径。
- UI/交互：改变新用户默认栏位状态可能压缩小窗口主视口；必须验证三档 MacBook 尺寸、右栏最大宽度、完整时间轴和专注模式往返。
- 安全：只接受本地图片并使用现有 FileReader/数据 URL 路径，不新增网络、IPC 或 Node 能力。
- 发布：修改主 HTML 后现有已安装 App 不会自动更新；本任务完成代码与验证，不覆盖用户安装目录，后续需单独重新打包/安装。

## 实施记录

- 假设：用户所说「自定义」按自定义颜色与本地图片纹理共同覆盖；右栏仍保留折叠能力，但所有内容入口直接进入固定布局。
- 关键决定：栏位状态属于本机 UI 偏好；地面外观属于场景项目数据。旧的已保存 UI 偏好继续尊重，只有没有偏好时采用新默认值。
- 国际化前置：通过合并提交 `6018297` 安全合入 `0d5bcb6`；主 HTML 冲突人工保留电影控制台结构和 i18n 运行时双方功能。本任务涉及的顶栏、模式轨、动态布局/主题/播放状态及地面控件全部使用 language key，同时扩展 `data-i18n-aria-label` 和 `data-i18n-tooltip`。
- 实际修改：移除左栏四个重复属性入口和 `rightPin`；新用户默认固定右栏与完整时间轴，普通属性入口直接固定展开，导演专注继续使用非持久临时 `peek`；模式轨使用即时自定义提示；右栏分隔条提供双三角、指针无过渡拖动及键盘调宽。
- 渲染修改：将栏位尺寸更新合并到主渲染帧，缓存主/监视器 renderer 宽高与 DPR，时间轴拖动期间关闭高度过渡，确保同帧以 render 结束且不重置未变化的监视器画布。
- 地面修改：场景增加可选 `ground` 外观，支持棋盘格、纯白、纯黑、自定义颜色和项目图片资产；旧项目、非法样式和缺失资产回退棋盘格；资产清理、自动保存、项目往返和全景导出阴影材质均保留。
