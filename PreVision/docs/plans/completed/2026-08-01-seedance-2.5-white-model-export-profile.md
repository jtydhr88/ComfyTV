## 用户问题

新增“Seedance 2.5 白模参考包”导出配置，以中性 clay 白模表达结构、机位和调度；白模覆盖只存在于同步单帧 render，任何成功、取消和异常都要精确恢复共享编辑器状态。输出脚本、实际采样帧、manifest 和 ZIP 必须同源可核验，并保持 project/history/autosave 零写。

## 目标

- 在现有底栏 Seedance 唯一入口内提供当前镜头/本场景白模参考包选择、三类用途说明、阶段进度、取消和双语/a11y 状态。
- 实现单次同步 renderer.render 的 clay 白模覆盖，以及独立 LIFO、exactly-once 恢复账本；普通导出和后续 transaction 不串白。
- 以 deterministic pure planner 统一 clip/frame/timestamp/manifest；每镜小于等于 29.5 秒，超限首写前拒绝；场景包一镜一 clip，总场景超过 30 秒只在 manifest 中生成确定性续写分组。
- 输出默认 1080 级、30fps、无音频；沿用当前 C5/浏览器下载链，并在 manifest/验收中如实声明保存方式。
- 覆盖 16:9、9:16、Follow、暂停/播放/drag/scrub、旧 project v1-v5、连续/取消/迟到回调 generation 隔离与真实 ZIP 反算校验。

## 非目标

- 不接 Seedance API、不调用付费生成、不导出 3D 源文件。
- 不新增 Electron chooser、原子替换、desktop/electron-ipc，不修改 electron/main.cjs、electron/preload.cjs 或桌面壳测试。
- 不实现单镜大于 29.5 秒自动切段，不改变普通导出的 codec fallback。
- 不写 project v5 新字段，不改变 history/autosave，不更新固定 App、稳定预览指针、GitHub 或 Pages。
- 不建立高级面板或第二套人物系统；可选彩色人物 ID 静帧仅在低耦合时评估，否则 manifest 明示另附角色图。
