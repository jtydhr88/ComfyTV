## 修改前后

- 修改前：副标题使用 `7.5px` 等宽字体，没有独立垂直位移；用户截图中字形底边明显高于 25px 应用图标底边。
- 修改后：副标题使用 `8.5px/1` 行高、`.11em` 字距和 `translateY(2px)`；主标题的字号、位置以及 42px 顶栏高度不变。
- 交互前后：验收从普通主界面开始，临时切换四主题和导演专注模式，结束时恢复石墨主题与普通主界面；左右栏、时间轴和项目状态均未改变。

## 目标窗口结果

### 1440×900

1. 图标边界为 `top=8px / bottom=33px`，副标题边界为 `top=24.28px / bottom=32.78px`，底边差约 `0.22px`。
2. 主标题底边约 `22.28px`，副标题顶边约 `24.28px`，两行没有重叠，视觉间距比基线更清晰。
3. 石墨、雾白、暮光、琥珀四主题的底边差均为约 `0.22px`，页面 `scrollWidth=clientWidth=1440`。

### 1728×1117

1. 副标题保持 `8.5px` 字号和 2px 下移，图标/副标题底边仍为 `33px / 32.78px`，差约 `0.22px`。
2. 42px 顶栏无裁切，页面 `scrollWidth=clientWidth=1728`。
3. 进入导演专注模式后副标题按原规则隐藏；退出后恢复显示和对齐。

### 1316×768

1. 命中 `max-width:1320px` 原有断点，「3D DIRECTOR」保持隐藏，品牌主标题和图标仍显示。
2. 顶栏宽度为 1316px，页面 `scrollWidth=clientWidth=1316`，没有水平溢出。
