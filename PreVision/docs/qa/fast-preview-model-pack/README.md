### `1440x900-model-pack-playback.png`

- 路径时刻：`0/25/50/75/100%`，对应 `0.00/1.25/2.50/3.75/5.00s`；海马与骑手缩放 `1.00`。五格使用同一固定世界相机：target `(-0.8, 1.9, -0.2)`、distance `6m`、theta `0.62rad`、phi `1.04rad`，不再随宿主位置或 yaw 共转。
- **任务级 PASS**：明显非共线的 Catmull-Rom 曲线路径五点不再从生产 tangent 取 `expected`。oracle 只读取实际播放产生的宿主位置：0% 用 `[0, .002]` 单边差分，内部点用 `[f-.002, f+.002]`，100% 用 `[.998, 1]`，再以 `atan2(Δx, Δz)` 得到独立 expected 并用 wrap-angle 比较 exact-f measured。五点 `expected/measured` 为 `-172.8/-172.9°`、`-179.9/-180.0°`、`131.4/131.4°`、`45.0/45.0°`、`-0.2/-0.2°`，显示误差依次为 `0.1/0.1/0.0/0.0/0.0°`，实际最大误差约 `0.001656rad`，覆盖 5 个不同显示 yaw。自动回归另证明：位置轨迹不变而 measured 统一 `+90°` 或反向时，五点误差分别全部 `>1.4rad` 或 `>3rad`，不能再由共享 tangent 共因假通过。
- **任务级 PASS**：五点中海马 x/z 旋转持续为 `0`；近景显示骑手骨盆落鞍、双腿贴合躯干两侧并落向脚蹬。骑手 yaw 同样通过 wrap-angle 对齐 expected，骑手与专用 anchor 的位置误差五点均为 `0.0000m`，没有漂移或重复偏移。
- **PASS**：右下 inset 是真实 Electron DOM 裁切，不是合成 mock；右栏实际宽度 `280px`，人物/巫师/道具/沉船/车辆/马匹/海马 7 个按钮全部在两列网格内可见，中心 `elementFromPoint` 逐一命中对应按钮。
- **PASS**：空场与三模型均真实调用 `clock.play()` 后采样。空场配置 `5000ms`、实际 `5001.4ms`、301 帧，median `59.9 FPS`、p10 `57.1 FPS`；模型包配置/实际均 `5000.0ms`、301 帧，median `59.9 FPS`、p10 `59.5 FPS`，为基线 median 的 `100%`。模型包采样期间时钟从 `0.600s` 前进到 `5.600s`，海马宿主移动约 `3.470m`，证明不是静态 rAF 自报。
- 可接受残余：不同显示器刷新率会限制可见 FPS 上限；该结果是本机开发预览，不是跨平台性能上限承诺。
- 任务级阻断：无；又一轮独立 R2 gate 尚未执行，本证据不得预称独立 PASS。

性能复现步骤：

1. 用 Electron 43.1.0、Node 22.23.1、隔离 userData，以 1440×900 CSS 内容视口和 device scale factor 1 打开当前生成 HTML。
2. 固定左右栏/时间轴状态、镜头、地面、光照与 8 秒镜头时长；先清空演员，`clock.seek(0)` 后 `clock.play()`，预热 20 帧，再采样 5000ms。
3. 用相同设置加入沉船、带 8 秒路径的海马及挂载的 fallback 巫师，重新 `clock.seek(0)` / `clock.play()`、预热 20 帧并采样 5000ms。
4. 对每个 rAF delta 换算 FPS，记录 sample/frame count、median、p10/p90、时钟前进和海马宿主位移；通过线为模型包 median ≥30 FPS 且 ≥空场 median 的 85%。

- 可接受残余：快速预览级低多边形表达、窄尺度单骑手约束、fallback 巫师不代表高精度人物、沉船无凹形/破碎/水体物理。
