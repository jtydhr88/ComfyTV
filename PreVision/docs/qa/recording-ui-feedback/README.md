## 目标尺寸和交互前后状态

### 1316×768

1. 在没有该预览源历史偏好的新用户状态进入页面。
2. 初始值为 `left=expanded`、`right=expanded`、`timeline=full`；右栏 336px，分隔条 6px，时间轴右边缘位于分隔条左侧。
3. 左模式轨不存在摄影机、角色、路径、灯光四个重复入口；右栏头部不存在图钉/二次固定按钮。
4. 收起右栏后进入 46px 属性轨；点击右侧摄影机入口后直接恢复固定右栏，`peek=false`，时间轴未被覆盖。
5. 场景模式按钮通过键盘聚焦后即时显示「场景与镜头」提示，伪元素状态为 `opacity=1 / visibility=visible`，按钮没有原生 `title`。
6. 时间轴手柄实际从约 199px 拖至 271px；拖动结束后 `resizing=false`，主 canvas 物理尺寸和 CSS 尺寸均为非零，导演区保持已渲染画面，页面错误栏为空。

### 1440×900

1. 切换至雾白日间，保持固定右栏和完整时间轴。
2. 实测主视口约 824×474px、时间轴约 824×323px、右栏 336px；时间轴右边缘小于等于右栏左边缘。
3. 右栏自身滚动可到达「场景背景」地面控件；棋盘格、纯白、纯黑和自定义颜色均完成切换。
4. 纯黑地面与周围黑色导演区连续，网格/外边框不残留；纯白与自定义颜色地面保留灯光、阴影和对象可读性。
5. 胶片琥珀也在相同布局中切换并检查，栏位状态和渲染画面未变化。

### 1728×1117

1. 切换暮光靛蓝后进入导演专注模式。
2. 专注态主视口约 1635×949px，右侧为 45px 属性轨，底部为约 104px 紧凑镜头条。
3. 退出专注后恢复 `expanded/expanded/full`，主题保持暮光靛蓝，页面错误栏为空。

## 补充交互验证

- 右栏分隔条在键盘聚焦时显示左右双三角；`ArrowLeft` 将 336px 调为 352px，`aria-valuenow` 同步更新。
- 分隔条方向键事件已阻止冒泡；调宽前后监视器标题均为 `S1 · C1 开场·远景`，不会误触上一镜/下一镜。
- 指针拖拽期间右栏进入无宽度过渡的 `resizing` 状态，结束后恢复普通状态；自动回归覆盖 280px 下限、半屏上限和宽度持久化。
- 自定义图片地面不通过人工系统文件选择器加载；自动回归覆盖本地图片资产引用、项目保存/重新载入、资产清理保留、全景导出阴影材质及缺失资产回退棋盘格。
- 四主题、左右栏状态、时间轴三态和导演专注全过程均未出现浏览器控制台 warning/error。
