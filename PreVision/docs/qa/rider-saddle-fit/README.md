## 产品边界

贴鞍默认姿态与历史默认值迁移只作用于白马宿主；车载和普通物体挂载继续使用既有通用姿态。马和人物分别复用现有对象统一缩放，UI 允许 0.3–3。此范围保证挂载锚点、朝向与数值稳定；人物与鞍具不会针对极端非等比创作尺寸执行人体 IK 或几何自动重塑，因此视觉贴合属于有界近似。
