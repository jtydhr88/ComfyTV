## 目标尺寸和交互前后状态

### 1316×768

1. 初始状态：左场景栏展开、右属性栏展开、时间轴为镜头条。
2. 左栏：点击栏头箭头后从 210px 收入模式轨（边界约 1px），主视口宽度扩展至 1223px；点击「场景与镜头」图标后恢复 210px。
3. 右栏：点击收起后进入 46px 属性轨；点击「调度路径」图标后进入 `peek`，336px 抽屉向左展开；`Escape` 后回到属性轨。
4. 时间轴：镜头条 110px → 完整调度 251px（轨道区 199px，主视口仍有 414px）→ 隐藏 37px（主视口 628px）→ 镜头条 110px。
5. 四主题依次切换后，选中、运镜、调度、录制/删除语义色仍可区分；工作区无水平溢出（`scrollWidth = 1316`）。

### 1440×900

1. 初始状态：雾白日间、左右栏展开、镜头条。
2. 尺寸结果：工作区 1440×836px；左栏 228px；右栏 336px；主视口 824×687px；底部状态栏 22px。
3. 最深的右栏属性可通过自身滚动到达，不挤压顶栏、主视口或镜头条；页面 `scrollWidth/scrollHeight = 1440/900`。

### 1728×1117

1. 进入前：左栏为 `expanded`、右栏为用户之前的固定状态、时间轴为 `filmstrip`。
2. 点击顶栏导演专注图标：场景内容栏收入模式轨，右栏临时呈现为 46px 属性轨，工具栏浮置，时间轴为 104px 紧凑镜头条；主视口 1635×949px。
3. 进入后 `data-left/data-right/data-timeline` 仍是进入前值；退出后恢复原栏位尺寸，不写入新布局偏好。
4. 页面与视口同宽（`scrollWidth = 1728`），无关键命令被遮挡。

## 额外验证

- 主题切换后 Three.js 场景背景、物体、摄影机路径和监视器输出保持原色。
- 石墨、雾白、暮光、琥珀均已真实渲染；刷新后恢复最后主题与左右栏/时间轴偏好，专注模式不跨刷新保存。
- 左右栏及专注切换后，主 WebGL canvas、导演台摄影机长宽比和监视器 renderer 重算正常。
- 界面操作期间浏览器控制台 0 条运行错误。
- 项目数据、摄影机、对象路径、时间轴、撤销栈和自动保存不变性由 `测试/冒烟测试.mjs` 的 UI v3 运行时用例保护。
