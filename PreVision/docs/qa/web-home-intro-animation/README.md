阶段：快速开发预览，未更新固定 App，未部署公网。

## 素材

- 正式运行时只使用用户提供的 `1.svg`–`6.svg`、视频优化副本与视频第 0 帧 poster；PDF、截图和原始母版未进入运行时。
- 原视频：3840×2160、30 fps、H.264/AAC、11.1 s、46,611,989 B。
- 发布副本：3840×2160、30 fps、H.264 High / AAC-LC 44.1 kHz 双声道、11.1 s、14,234,568 B、`faststart`；保留原片声音，约为原体积的 31%。
- poster：1920 像素宽 JPEG，158,695 B；由原视频第 0 帧生成，用于避免 ACTION 启动跳帧。
- SVG 均为路径轮廓，无外部字体和网络依赖；素材授权按用户本任务提供处理，没有上传到外部服务。

## 行为与性能边界

- 页面只有小红书链接和 ACTION 按钮可交互；均有语义化元素、键盘焦点和 language-key 无障碍名称。
- ACTION 只发起一次 `video.play()`；85 ms 点击声已离线混入视频音轨开头，随后保留原片声音，避免独立 Web Audio 与有声视频争抢浏览器的用户手势授权。
- 视频 URL 带发布版本标识，避免快速预览中替换媒体后，浏览器继续复用旧文件的 Range 分段缓存。
- 正常浏览器点击直接以有声模式播放；若嵌入式浏览器明确返回 `NotAllowedError`，会在同一次启动中以短暂静音方式取得播放许可后立即恢复音轨，避免 ACTION 完全无响应。
- 桌面 poster 的亮度统计约 97.8、视频首帧约 100.0；启动/播放状态使用 `brightness(.975)` 与 180 ms 过渡补偿 JPEG poster 切换到视频解码帧时的提亮跳变。
- 溶解使用平滑 CSS 位移/模糊与最多 520 个固定种子颗粒：最多 56 个 6–16 px 不规则大块先松散，最多 160 个 2.3–7.1 px 中块承接，其余 0.55–2.55 px 微粒延迟散开。三档分别缩小、漂移并淡出，Canvas DPR 上限为 2，约 4.3 s 后停止并清空。
- `prefers-reduced-motion: reduce` 下不创建颗粒，只使用简短退出。
- ACTION 启动后立即锁定重复触发；媒体拒绝/错误恢复首帧，后台切换暂停并在返回时续播，BFCache 返回重置。
- 视频结束发出 `prevision:intro-complete`，`detail.target` 为 `/director/`；页面本身不导航。`window.PreVisionIntro.onComplete`为下一任务预留回调位。
