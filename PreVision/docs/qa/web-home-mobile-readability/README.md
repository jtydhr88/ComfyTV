## 对比度

承托背景固定为不透明 `#f6e8c8`，不依赖影片、渐变采样、阴影或透明叠色。按 WCAG 相对亮度公式计算：

| 前景 | 用途 | 对承托背景 |
| --- | --- | ---: |
| `#241710` | tagline 深棕文字 | 14.35:1 |
| `#2a1911` | 功能区深棕文字 | 13.89:1 |
| `#000000` | 品牌/功能黑色文字 | 17.30:1 |
| `#e44736` | 功能红色图标 | 3.29:1 |
| `#180e09` | 移动端焦点轮廓 | 15.64:1 |

普通文字均高于 4.5:1，红色图标和焦点轮廓均高于 3:1。
