# ComfyTV

ComfyTV turns ComfyUI into a **canvas app for making media** — and keeps going, all the way to a full media workbench. Every operation is its own node, and results flow downstream automatically. Chain stages into a complete pipeline: **generate → pick → edit → composite → export**, across image, video, audio, music, panorama, 2D layers, and 3D.

**~190 stages** ship today. Every one of them has its own page in the Node Reference.

## What makes ComfyTV different

<CardGroup cols={3}>
  <Card title="Per-node Run" icon="play">
    Most stages have their own Run button. Running one stage does not re-run the whole graph — downstream stages consume the snapshot of the last output.
  </Card>
  <Card title="Project-centric" icon="floppy-disk">
    Stages belong to a project. Every output is kept with full history and restores on reload.
  </Card>
  <Card title="Rich in-node editors" icon="sliders">
    A layered 2D editor with PSD import/export, a storyboard workbench, piano rolls, 3D viewports, scopes — plus live previews on most video effects.
  </Card>
  <Card title="Your workflows, bound in a GUI" icon="diagram-project" href="/guides/custom-workflows">
    Import any ComfyUI workflow as JSON, bind its inputs in the sidebar editor, save presets, and star a default per stage.
  </Card>
  <Card title="Part of the ecosystem" icon="puzzle-piece" href="/guides/bridges">
    Subgraphs and third-party plugins just work; Bridge nodes connect any plugin, and remote ComfyUI machines can run stages for you.
  </Card>
  <Card title="Built-in libraries" icon="box-archive" href="/guides/sidebar">
    A project asset library (image / video / audio / 3D) and a resource library (LUTs, fonts, SoundFonts), each with its own sidebar panel.
  </Card>
</CardGroup>
