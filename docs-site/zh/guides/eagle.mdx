## 分工

内置的[资产库](/guides/sidebar)是**工作台**:资产跟着项目走,通过 `@` 引用喂给 stage,剪辑时有 proxy。Eagle 是**跨项目的档案馆和采集入口**:评星、标签、文件夹、全文与 AI 搜索、浏览器剪藏——一份超越任何单个项目的精选集。

集成把两边双向打通:

- **出**:生成结果流进 Eagle(手动或自动),按项目归档,永远能靠当时的 prompt 搜回来。
- **进**:Eagle 里的任何东西——包括你从网上剪藏的参考图——都能在侧边栏浏览,拖上画布变成普通资产。

有一个模型层面的事实要先接受:**Eagle 导入任何文件都会拷贝进它的 `.library`**,没有"引用"模式。ComfyUI 的 output 原文件原地不动(ComfyTV 永不删文件),Eagle 里那份就是归档正本。

## 前置与设置

- **Eagle 桌面应用**(Eagle 4;4.0 Build 21+ 解锁更强的 V2 API,老版本回落 V1,搜索较弱)。
- 一个你愿意接收 ComfyTV 产出的库(至少是专用文件夹)。推荐**专门建一个库**——Eagle 同时只能打开一个库。

在 ComfyTV 侧边栏打开 **设置 → Eagle 集成**:

| 设置 | 含义 |
|---|---|
| **启用 Eagle 集成** | 总开关。侧边栏出现 Eagle 页签,资产菜单出现发送动作。 |
| **Eagle API 地址** | Eagle 本地 API,默认 `http://127.0.0.1:41595`。本机访问不需要 token。 |
| **钉死的资源库路径** | ComfyTV 专用的 `.library` 目录。强烈建议填——见下面的三态。 |
| **发送目标文件夹** | *手动*发送的条目归入的 Eagle 文件夹(自动创建)。 |
| **产出自动沉淀到 Eagle** | 默认关。开启后每次 stage 渲染自动归档——见下文。 |

## 三态

Eagle 的 API 永远只作用于**当前打开的**库。ComfyTV 探测 Eagle 并得出三种状态,显示在 Eagle 页签标题的圆点上:

| 状态 | 何时 | 读 | 写 |
|---|---|---|---|
| **在线** | Eagle 正开着钉死的库 | 完整 API:搜索、过滤、文件夹 | 发送立即执行 |
| **只读** | Eagle 没开,或开着*别的*库 | ComfyTV 直接读钉死的 `.library` 磁盘目录,浏览照常 | 发送**排队** |
| **离线** | 应用和钉死路径都不可达 | — | 发送排队 |

队列就是安全机制:你开着个人库的时候,绝不会有东西误灌进去。ComfyTV 下次探测到钉死的库打开时,排队条目自动补发(Eagle 页签有横幅显示数量,也可手动补发)。

## 浏览与取用

侧边栏的 **Eagle** 页签列出整个库,带搜索、文件夹下拉和媒体类型过滤(V2 API 下搜索是全文的,标签也能命中)。视频卡悬停即播,音频卡有内联试听按钮。

要*用*一个条目:

- **直接拖上画布。** 条目自动导入资产库,并在落点生成 loader 节点——之后它和原生资产完全一样(接 stage、`@` 引用、proxy)。
- 或者悬停卡片点**导入箭头**,只入资产库不落节点。

导入的条目是 `source: eagle` 的普通资产;重复导入同一条目会复用已有资产,不会重复。

## 发送到 Eagle

在资产库右键任意资产选 **发送到 Eagle**。文件导入 Eagle(归入*发送目标文件夹*),打上 `comfytv` 标签,批注自动填入从输出历史恢复的生成溯源——stage、项目、工作流、prompt 和参数。日后在 Eagle 里搜那段 prompt,就能定位到当时那张图。

## 自动沉淀

打开 **产出自动沉淀到 Eagle**,每次 stage 渲染(图片 / 视频 / 音频,批图逐张)在落盘的瞬间自动归档:

- 归入以**项目**命名的 Eagle 文件夹(自动创建),
- 标签为 `comfytv` + 项目名,
- 批注带完整溯源(工作流、prompt、参数)。

归档走队列,在工作线程入队,绝不阻塞生成;Eagle 没开或开着别的库时条目攒在队列里,之后自动补发。这套支撑的正是社区主流用法:放开手生成,回头在 Eagle 里靠评星筛片——档案天然是全的。

## AI 搜索与找相似

如果装了 Eagle 官方的 **AI Search** 插件且其后端在运行,两个功能自动点亮:

- 搜索框旁的 **AI 开关**——按含义搜("海浪上的红船")而非按关键词;
- 每张卡上的**找相似**——全库以图搜图。

插件未就绪时这些入口保持隐藏。

## 搭配 Eagle 的 MCP 服务(可选)

Eagle 还有官方 **MCP Server** 插件(默认 `http://127.0.0.1:41596/mcp`,streamable HTTP)。它与本集成相互独立,但和 [ComfyTV 的 MCP](/guides/mcp) 搭配很好:agent 可以读取你在 Eagle 里的当前选中、批量打标签、整理文件夹、写批注,同时通过 ComfyTV 工具驱动生成。

```bash
claude mcp add --transport http eagle http://127.0.0.1:41596/mcp
```

## 说明与边界

- Eagle 导入即**拷贝**;把库里那份当归档正本。ComfyTV 自己的 output 文件无论如何原地保留。
- 只读模式的浏览直接读库的磁盘格式;写入永远不碰磁盘格式——一律走 Eagle API。
- V2 API 之前的 Eagle 版本,搜索回落到 Eagle V1 的关键词匹配。
