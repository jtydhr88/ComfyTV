ComfyTV 在 ComfyUI 左侧边栏注册一个 **ComfyTV** 页签，里面又分**八个 tab**——所有不在画布节点上的东西都在这里：工作流配置、媒体库、提示词片段、按 kind 的工作流/参数管理、预设、资源、远程服务器、设置。上次用的 tab 会被记住，刷新后自动回到原位。

（启用 [ComfyTV Bot](/guides/bot) 后，侧边栏还会出现第二个 ✨ 图标——那是内嵌聊天代理，另有专页介绍。）

![ComfyTV 侧边栏页签](/images/sidebar-tabs.png)

---

## 工作流 —— 配置选中 stage 的工作流

在画布上选中一个 stage 节点，这个 tab 就变成它的**工作流配置编辑器**——哪个工作流节点收提示词、哪个 `LoadImage` 吃上游第 N 张图、种子接到哪里，等等。

![工作流配置侧边栏](/images/sidebar-overview.png)

从上到下会看到：

- stage 的 **kind** 和它当前选中的**工作流**。如果节点的 workflow 下拉框还是空的，或者工作流还没完成一次性准备（新导入的工作流第一次运行时自动完成，属正常），编辑器会直接提示，而不是显示表单。
- 工作流是 🔗 [链接来的](/guides/custom-workflows)时会有一条**链接来源**横幅：它存在 ComfyUI 自己的库里，在那边保存即实时生效。可以在这里 **Unlink**；如果底层文件被移动或删除，横幅会变成断链警告。
- **Notes** —— 随工作流预设携带的自由文本备注（坑点、模型要求）。
- **暴露的 widget 与绑定** —— 工作流的节点列表，可搜索、可按分组 chip 过滤，逐项编辑绑定。改动即时生效，不用重启。
- **⇩ Export preset.json** —— 把当前绑定打包，与工作流文件一起分享。

编辑器的完整攻略见 [sidebar-config-editor.zh.md](/guides/sidebar-config-editor)。

## 资产库 —— 媒体库

![资产库面板](/images/assets-panel.png)

存放你想反复使用的**图片、视频、音频、3D 模型**——独立于任何单个项目。

- **入库**：上传按钮，或**直接把文件拖到面板上**。面板打开时还会**扫描 ComfyTV 的媒体目录**（⚙ 菜单里也有*扫描文件夹*），把新发现的文件自动收养进库。
- **整理**：创建**分类**并给资产打标——一个资产可以带多个标签。按分类 chip、按媒体类型（图/视频/音频/模型，带数量）过滤，或按名字搜索。网格/列表两种视图。
- **使用**：**把资产拖到画布上**——ComfyTV 会自动创建对应的 *Load … from Asset* 节点并接好——或用卡片菜单的*加载为节点*。菜单还有*查看大图*（灯箱）、*生成代理*（视频）、*编辑标签*、*重命名*、*删除*。删除只移除库条目，磁盘文件不动。
- 资产图片还能直接插进 stage 的提示词当参考图——见本页最后的「提示词引用」。

## 条目 —— 可复用的提示词片段

![条目面板](/images/entries-panel.png)

项目级的**文本片段**，在任何 stage 的提示词里用 `@label` 引用。

- 每个条目有**标签**（以字母或下划线开头——中文也行——后面接字母/数字/`_`/`-`）和**内容**。运行时提示词里的 `@label` 展开为内容；未知 token 保持原样。
- 删除条目后，已有的 `@label` token 自动退回字面文本。
- **导入/导出**把本项目全部条目做成 JSON 备份来回搬（导入时重复行自动跳过）。
- 也可以**不离开提示词**直接建片段：输入 `@`，敲一个不存在的标签，提及弹窗会提供就地创建。

## Stage 管理 —— 按 kind 管理工作流与自定义参数

![Stage 管理](/images/stage-manager.png)

在顶部下拉框选一个 **stage kind**，下面分两节。

**Workflows** —— 该 kind 注册的全部工作流，也就是画布上对应 stage 节点下拉框里的内容：

- 徽章说明每一行的来历：**built-in**（随 ComfyTV 发布）、**linked**（指向 ComfyUI 原生库）、**new**（最近一次扫描新发现）、**default**，以及健康警告——*文件丢失*、*不是 GUI 格式*、*API 未生成*（首跑前属正常）。
- 悬停某行可 **★ 设为默认**——此后新建的该 kind stage 默认选中它。
- 可在这里 **Import** JSON，或把文件丢进 `user/comfytv/workflows/<kind>/` 后点 **Rescan**——直接重扫磁盘上的库，不用重启后端。

**Parameters** —— 给这个 kind 的所有 stage 定义你自己的额外控件：

- 参数有标签、类型（**float / int / string / boolean / combo**）、默认值和类型相关配置（数字的 min/max/step、combo 的选项、字符串的 placeholder）。
- 之后在该 kind 的任意 stage 卡片上**挂载**这个参数并按节点设值；值会合并进 stage 的运行参数，再在**工作流** tab 里用绑定接进工作流。

## 预设 —— 所有已保存的 stage 预设

![预设面板](/images/presets-panel.png)

你在 stage 卡片上保存过的全部参数预设，按 stage 类型分组。在这里重命名或删除；创建在节点本体上完成（预设条的 **Save preset** 按钮）。内置预设有标记且不能被覆盖。

## 资源 —— LUT、字体、SoundFont

![资源面板](/images/resources-panel.png)

节点要消费、但又不算媒体资产的文件：

| 类别 | 格式 | 消费方 |
|---|---|---|
| **LUT** | `.cube` `.3dl` `.dat` `.m3d` `.csp` | Video LUT（带实时预览） |
| **字体** | `.ttf` `.otf` `.woff` `.woff2` | Title / Subtitles / Annotate、图层编辑器文字 |
| **SoundFont** | `.sf2` `.sf3` | Score Synth（SF2） |

按组上传、重命名、删除。stage 在**远程服务器**上运行时，预检会核对远端是否有同样的资源——缺失或内容不一致会弹警告（可选*仍然运行*）。

## 服务器 —— 让 stage 跑在别的机器上

![服务器面板](/images/servers-panel.png)

注册局域网里的其他 ComfyUI 实例（名称/主机/端口），stage 就会多出一个 **Run on** 下拉框——重活扔给楼上的 GPU 机器、轻活留在本机，多台并行。结果永远落回本机。

- **Test connection** 显示在线/离线和队列状态（运行中/排队中、其中多少是 ComfyTV 发的）。
- **能力探测**报告远端的 ComfyTV 版本——或警告那边根本没装 ComfyTV——并列出缺失的节点。预检会硬拦注定失败的运行（没装 ComfyTV、缺节点），资源缺失则只警告。
- 服务器可随时禁用或删除；指向它的 stage 自动回退到本机运行。

## 设置 —— 备份、MCP 与 Bot

两组全局开关，存入 ComfyTV 数据库：

- **备份**：服务器启动时自动快照 ComfyTV 数据（开关、保留份数、自定义路径），外加*立即备份*按钮。
- **Agent 与 MCP**：**启用 MCP 服务**开放 [Agent 接入(MCP)](/guides/mcp) 里介绍的 agent 端点；**启用 ComfyTV Bot** 显示 [ComfyTV Bot](/guides/bot) 内嵌聊天代理。两者**默认关闭**；Bot 开关依赖 MCP，MCP 打开后才可用。关掉 MCP 会连带关掉 Bot，保存后 ✨ 图标即时出现或消失。

## 提示词引用

侧边栏的各个库直接接进每个 stage 的提示词框。

![提及弹窗](/images/prompt-mentions.png)

在提示词里输入 **`@`** 打开提及弹窗：

- **`@image_N`** —— 内联引用 stage 接进来的图片槽位（「让 @image_0 的角色穿上 @image_1 的衣服」）。chip 颜色与输入槽位一一对应，一眼能看出指的是哪张图。运行时每个 token 会按实际发送批次展开为对应序数。
- **`@片段`** —— 按标签插入「条目」tab 里的片段。输入一个还不存在的标签，弹窗会提供**就地创建**。
- **资产图片** —— 直接从资产库插入一张图；运行时作为**参考图**发送，并占用工作流的一个参考槽位。

### 钉住的图片参考

![图片参考](/images/image-refs.png)

吃图的 stage 还有一条 **Image references** 参考图条：**不接任何线**，直接把资产库的图片钉到 stage 的参考槽位上。两张图钉同一槽位、钉图覆盖了上游连线、或钉的图多于工作流绑定的槽位数时，都会给出警告。

### 提示词助手

生成类卡片上的 ✨ **提示词助手**提供快速起手（人像、风景、产品……）、模板（分镜宫格、角色设定表、情绪板、放大）和按 质量/光照/情绪/风格 分组的增强 tag——点一下追加到提示词。
