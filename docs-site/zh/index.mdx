# ComfyTV

ComfyTV 把 ComfyUI 变成一个**做媒体的画布应用**。每个操作都是独立节点，结果自动向下游流动。把各个阶段串成完整流水线：**生成 → 挑选 → 编辑 → 合成**，覆盖图像、视频、音频、全景和 3D。

## ComfyTV 的独特之处

<CardGroup cols={3}>
  <Card title="逐节点运行" icon="play">
    大多数阶段有自己的运行按钮。运行单个阶段不会重跑整张图。
  </Card>
  <Card title="快照向下游流动" icon="diagram-project">
    阶段一旦运行，结果保存为快照，供下游阶段直接复用。
  </Card>
  <Card title="节点内富交互" icon="sliders">
    裁剪、旋转、镜像、全景视口、时间线、编辑器都在浏览器里实时运行。
  </Card>
</CardGroup>
