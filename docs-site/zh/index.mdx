# ComfyTV

ComfyTV 把 ComfyUI 变成一个**做媒体的画布应用**——并且一路做深，做成完整的媒体工作台。每个操作都是独立节点，结果自动向下游流动。把各个阶段串成完整流水线：**生成 → 挑选 → 编辑 → 合成 → 导出**，覆盖图像、视频、音频、音乐、全景、2D 图层和 3D。

目前共有 **约 190 个 stage**，每一个在节点参考里都有独立文档页。

## ComfyTV 的独特之处

<CardGroup cols={3}>
  <Card title="逐节点运行" icon="play">
    大多数阶段有自己的运行按钮。运行单个阶段不会重跑整张图——下游消费的是上游最近一次输出的快照。
  </Card>
  <Card title="以项目为单位" icon="floppy-disk">
    阶段归属于项目。每次输出都带完整历史保存，刷新页面后自动恢复。
  </Card>
  <Card title="节点内富编辑器" icon="sliders">
    带 PSD 导入导出的 2D 图层编辑器、故事板工作台、钢琴卷帘、3D 视口、示波器——多数视频特效还有实时预览。
  </Card>
  <Card title="GUI 里绑定你的工作流" icon="diagram-project" href="/zh/guides/custom-workflows">
    任何 ComfyUI 工作流以 JSON 导入，在侧边栏编辑器里绑定输入，保存预设，按 stage 星标默认工作流。
  </Card>
  <Card title="融入 ComfyUI 生态" icon="puzzle-piece" href="/zh/guides/bridges">
    子图、第三方插件开箱即用；Bridge 节点可接入任意插件，远程 ComfyUI 机器也能替你跑 stage。
  </Card>
  <Card title="内置双库" icon="box-archive" href="/zh/guides/sidebar">
    项目级资产库（图/视频/音频/3D）和资源库（LUT、字体、SoundFont），各有独立侧边栏面板。
  </Card>
</CardGroup>
