## 这个节点做什么

**艺术特效 (Art FX)** 用 GPU（torch）艺术风格滤镜处理整段 `COMFYTV_VIDEO`，并在 **▶ Run** 时写出新快照；源片段保持不变。用 **mode** 选择四种外观之一——每种外观只读取下面参数中属于自己的那一部分。

输入与输出都是 `COMFYTV_VIDEO`。若要对接原生 ComfyUI 节点，请插入 **Bridge**——见[桥接指南](https://github.com/jtydhr88/ComfyTV/blob/main/docs/bridges.md)。

## 何时使用

- 把实拍转成扁平、色阶化的**卡通 (cartoon)**，带描边墨线。
- 给片段做手绘般的**炭笔 (charcoal)** 或**浮雕 (emboss)** 处理。
- 用印刷风的**半调 (halftone)** 网点营造漫画或复古海报感。

## 参数

### mode
外观。选项：`cartoon`、`charcoal`、`emboss`、`halftone`。默认 `cartoon`。

### threshold
边缘/线条灵敏度，`0.01`–`1.0`（步长 `0.005`），默认 `0.12`。越低捕捉越细、越多的边缘；越高只保留强轮廓。由基于边缘的外观（cartoon/charcoal）使用。

### levels
颜色色阶化级数，`2`–`32`，默认 `8`。级数越少画面越扁平、更具图形化的色带（cartoon）。

### diff_space
边缘检测间距，`1`–`4`，默认 `1`。越大在更宽的像素间隔上采样边缘，得到更粗/更糙的线条。

### edge_scale
边缘线条强度/粗细倍数，`0.1`–`8.0`（步长 `0.05`），默认 `1.5`。调高得到更粗的轮廓。

### scatter
笔触散布/抖动，`1`–`4`，默认 `1`。越高笔触越粗糙、越不均匀（炭笔风）。

### color_mix
将多少原始颜色混回风格化结果，`0.0`–`1.0`，默认 `0.0`。为 `0` 时完全风格化；向 `1` 提高会把源颜色混回来。

### invert
翻转线条或浮雕结果的明暗极性。默认关闭。

### azimuth / elevation
浮雕光照方向。**azimuth** `0`–`360°`（步长 `1`，默认 `135`）是绕画面的光照角度；**elevation** `0`–`90°`（步长 `1`，默认 `30`）是其高度。由 **emboss** 外观使用。

### emboss_width
浮雕起伏宽度（像素），`1.0`–`40.0`（步长 `0.5`），默认 `10.0`。越宽起伏越深、越有雕塑感。

### dot_radius
半调网点半径（像素），`1.0`–`10.0`（步长 `0.5`），默认 `4.0`。网点越大网屏越粗。

### angle_c / angle_m / angle_y
半调每通道的网屏角度，各为 `0`–`360°`（步长 `1`）。默认 `15`（青）、`45`（品红）、`0`（黄）。错开它们可避免摩尔纹，得到经典的 CMY 玫瑰花纹。

## 输出

| 输出 | 类型 | 含义 |
|---|---|---|
| **video** | `COMFYTV_VIDEO` | 风格化后的片段，作为新的项目快照 |

## 提示

- 许多参数只对自己的外观有效：**emboss_width**/**azimuth**/**elevation** 仅浮雕；**dot_radius**/**angle_c/m/y** 仅半调；**levels** 主要用于卡通。在错误的模式下改动它们不会有效果。
- 若风格化片段显得太单色，可略微调高 **color_mix**。
