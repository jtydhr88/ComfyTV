## 本节点的作用

**Audio Beats & Notes(音频节拍与音符)** 对音轨做音乐信息检索(MIR):检测节奏事件并输出为动画**关键帧**(每个事件把所选字段设为某值)以及文本**标签**(每个事件时刻的标记)。用 **mode** 选择检测内容:节拍、起音或音符事件。关键帧让下游节点在每拍脉动某个参数;标签可驱动标记或切点。

它接受 `COMFYTV_AUDIO` 快照或 `COMFYTV_VIDEO`(使用其音轨;audio 优先)。输出两路 `COMFYTV_TEXT`(keyframes 与 labels),并带有 ▶ **Run**。

若要与原生 ComfyUI 的 `AUDIO` 互通,请插入 **Bridge** — 见 [bridges.md](https://github.com/jtydhr88/ComfyTV/blob/main/docs/bridges.md)。

## 何时使用

- 让某元素在音乐每一拍上脉动、缩放或闪烁。
- 在每次鼓点/起音处放置剪辑标记或标签,做音乐视频卡点。
- 从旋律线提取音符事件时序。

## 参数

### mode
检测内容:`beats`(默认)— 稳定的节奏脉冲;`onsets` — 每个音符/打击起音;`notes` — 离散音符事件。

### threshold
检测灵敏度 — 事件需多强才被计入。范围 **0.05 到 1.0**,默认 **0.3**。越低捕获越多(且更弱)的事件;越高只保留显著者。

### min_gap_s
检测到的事件之间的最小间隔,单位秒。范围 **0.01 到 1.0**,默认 **0.05**。调高可避免单次敲击被重复触发。

### field
生成的关键帧驱动哪个动画字段:`v`(默认,通用值)、`scale`、`opacity`、`x`、`y` 或 `rotation`。这是每个检测事件将打帧的属性。

## 输出

| 输出 | 类型 | 含义 |
|---|---|---|
| **keyframes** | `COMFYTV_TEXT` | 关键帧数据:在每个检测事件处对所选 **field** 打帧 |
| **labels** | `COMFYTV_TEXT` | 每个检测事件时刻的文本标记 |

## 提示

- 若检测过密,调高 **threshold** 并/或 **min_gap_s**;若漏拍,则调低。
- `beats` 跟随速度栅格;`onsets` 在每个起音触发(更密)。按你要驱动的内容选择。
- 输入越干净帮助越大 — 先跑 **Audio Stem Split**,分析独立鼓轨以获得更准的节拍检测。

## 相关节点

- **Audio Reactive** — 用连续音频包络而非离散事件来驱动字段。
- **Audio Stem Split** — 抽出鼓轨以提升节拍/起音精度。
