## 这个节点做什么

**音频分割**在波形时间线上放一个切点(**split_s**),产出两条音频快照:**audio_a**(切点前)和 **audio_b**(切点后)。和音频剪辑一样,输入接音频或视频都行(视频取音轨切)。

两段都会存入项目历史,各自可以喂给图上不同的分支。

## 什么时候用

- 把长段配乐切成前奏和主体,分开使用
- 在场景边界切开旁白,两半路由到不同视频
- 想同时保留切点两侧(音频剪辑会丢掉一侧)

## ComfyTV 的设计

- **一刀两出**:切点在与音频剪辑同一套波形时间线上拖动;两个结果文件都写盘入库。
- **Stage** + **▶ Run**:对上游快照重切;下游各读各的那半。
- **零 GPU**:PyAV 磁盘处理。

## 类型(COMFYTV_* vs 原生 ComfyUI)

| ComfyTV 类型 | 是什么 | vs ComfyUI |
|---|---|---|
| `COMFYTV_AUDIO` | 音频 URL 快照 | 经 Bridge 与 `AUDIO` 互转 |
| `COMFYTV_VIDEO` | 视频 URL 快照(取音轨) | 经 Bridge 与 `VIDEO` 互转 |

## 参数

### audio(输入,可选)
源 `COMFYTV_AUDIO`。和 **video** 二选一。

### video(输入,可选)
源 `COMFYTV_VIDEO`,切其音轨。

### split_s
切点位置(秒),波形上拖动。

## 输出

| 输出 | 类型 | 含义 | 下游 |
|---|---|---|---|
| **audio_a** | `COMFYTV_AUDIO` | 切点前一段 | 任意音频消费者 |
| **audio_b** | `COMFYTV_AUDIO` | 切点后一段 | 任意音频消费者 |

## 一步步来

1. 接音频(或视频)源。
2. 在波形上拖切点,两侧都试听。
3. **▶ Run**;把 **audio_a**、**audio_b** 各接各的去处。

## FAQ

**Q:我只要其中一半。**  
A:用**音频剪辑** — 一个范围进,一条输出出。

**Q:split_s 在 0 或超出结尾?**  
A:会有一侧为空;把切点放在源时长以内。

## 相关节点

- **音频剪辑(Audio Trim)** — 只留一个范围
- **Audio Crossfade** — 带过渡地把两段接回去
- **Mux · Audio** — 把某段合到视频上
