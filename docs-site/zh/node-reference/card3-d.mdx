## 这个节点做什么

本节点把 `COMFYTV_VIDEO` 素材映射到一个平面上，并在 3D 中变换该平面——在透视相机下平移、旋转、缩放它——再把结果渲染回 2D。因为这是真正的 3D 投影（而非平面 2D 扭曲），倾斜卡片会产生正确的透视缩短，就像 Nuke 里的 Card 节点或 After Effects 里的 3D 图层。

它在 Torch 后端作为 fx-spec 处理。若无平移、无旋转、缩放为 1.0，则原样透传。输入与输出都是 `COMFYTV_VIDEO`。要把结果交给原生 ComfyUI 节点，请插入 **Bridge**——见[桥接说明](https://github.com/jtydhr88/ComfyTV/blob/main/docs/bridges.md)。

## 何时使用

- 伪造 3D 相机运动——让素材在透视中摆动，用于标题卡或揭示。
- 在合成中把底板倾斜放到虚拟地板/墙面上。
- 制作简单的视差或「空间中的照片」外观。

## 参数

### fov
相机视场角，单位为度，范围 5 到 140（默认 40）。越低是越长焦的镜头（透视更平）；越高是广角（卡片倾斜时透视更强）。

### tx / ty / tz
在 3D 中平移卡片。`tx` 和 `ty` 水平/垂直移动它，各自范围 -4.0 到 4.0（默认 0）。`tz` 把它推向或推离相机，范围 -0.95 到 6.0（默认 0）——负值拉近（变大），正值推远（变小）。

### rx / ry / rz
旋转卡片，单位为度。`rx`（俯仰）和 `ry`（偏航）各自范围 -89 到 89（默认 0），在透视中倾斜卡片；`rz`（滚转）范围 -180 到 180（默认 0），在平面内旋转它。

### card_scale
卡片整体缩放，范围 0.05 到 8.0（默认 1.0）。在放入场景前调整平面大小。

## 输出

| 输出 | 类型 | 含义 |
|---|---|---|
| **video** | `COMFYTV_VIDEO` | 经 3D 变换后再渲染回 2D 的素材 |

## 提示

- 让 `rx`/`ry` 保持在 ±89 以内——卡片无法旋转到完全侧对。
- 想要含蓄透视时用较低的 `fov`（长焦），戏剧性倾斜时用较高的 `fov`。
- 结合 `tz` 与旋转，营造卡片从深处摆入的效果。

## 相关节点

- **Z Defocus** — 添加景深，让倾斜的卡片显得更 3D。
- **360 Projection** — 用于球面而非平面的 3D 变换。
