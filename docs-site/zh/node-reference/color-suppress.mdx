## 这个节点做什么

Color Suppress（颜色抑制）降低素材中特定色相的存在感。它为六种颜色 —— 红、绿、蓝、青、品红、黄 —— 各提供一个滑块，每个控制该颜色被抑制的程度。它是 Despill 更通用的表亲：不只清理绿/蓝幕，你可以压下任何偏色，并可选在此过程中保持整体亮度不变。

输入与输出都是 `COMFYTV_VIDEO`。它作为实时 fx 预览滤镜运行（输出一个 fx spec 并直通），因此无需完整渲染即可预览结果。若六个滑块全为 0，则原样直通片段。

## 何时使用

- 需要压下某种偏色（如品红漏光、过蓝的天空）。
- 你想抑制绿/蓝溢色，同时还要清理另一种不需要的色相。
- 你需要针对一两种颜色的细微调色校正。

## 参数

### red / green / blue / cyan / magenta / yellow
每种颜色一个抑制量。各范围 `0.0`–`1.0`，默认 `0.0`（不改变）。调高滑块以去除更多该颜色。任意组合均可；全部为 0 即直通。

### preserve_luma
开启时，在抑制颜色的同时保持每个像素亮度不变，使去色处不变暗。默认关闭。

### output
`image`（默认）返回校正后的画面；`matte` 返回由抑制推导出的灰度遮罩。

## 输出

| 输出 | 类型 | 含义 |
|---|---|---|
| **video** | `COMFYTV_VIDEO` | 抑制后的图像；`output` 为 `matte` 时为遮罩。 |

## 提示

- 抑制强色时开启 `preserve_luma`，避免形状与细节发糊。
- 对于专门的绿/蓝幕边缘溢色，**Despill** 是专用工具；当不需要的颜色不是幕布色时用 Color Suppress。
- 要与原生 ComfyUI 节点互通，请插入 **Bridge**。见 [bridges.md](https://github.com/jtydhr88/ComfyTV/blob/main/docs/bridges.md)。

## 相关节点

- **Despill** —— 专用的绿/蓝幕溢色去除。
- **Keyer** / **Select0r** —— 从颜色产生遮罩，可与 Color Suppress 互补。
