## 节点用途

**Hue Correct（色相校正）** 是一款"色相对某量"的调色工具，类似合成软件（Nuke、Fusion）里的 Hue Correct 节点。你不是移动某个全局滑块，而是沿*色相环*画曲线：对每个色相（红、黄、绿……）分别决定改变多少饱和度、明度、某个色彩通道，或色相本身。非常适合精准修复 —— 只给红色去饱和、只把绿色调冷 —— 同时保持其余部分不变。

它输入输出均为 `COMFYTV_VIDEO`，在 torch 后端（`hue_correct`）上渲染，因此带有 **▶ Run**，卡片上有实时预览。所有曲线存于一个 JSON 对象中；若没有任何曲线至少含两个点，片段原样通过。

要与原生 ComfyUI 节点互通，请加一个 **Bridge**（见 [Bridge 指南](https://github.com/jtydhr88/ComfyTV/blob/main/docs/bridges.md)）。

## 何时使用

- 只给某个问题颜色去饱和（例如偏红的肤色）
- 在不做全局旋转的前提下平移特定范围的色相
- 提升或压低某一色带的明度
- 在某色相范围内抑制单个通道（`*_sup` 曲线）

## 参数

### curves
一个由色相驱动的曲线组成的 JSON 对象。每个键对应一列沿色相的 `[x, y]` 点（x = 色相环上的位置，0…1）。可识别的键：

- `sat` —— 饱和度对色相
- `lum` —— 明度对色相
- `red`、`green`、`blue` —— 各色彩通道对色相
- `r_sup`、`g_sup`、`b_sup` —— 逐通道抑制对色相
- `hue` —— 色相偏移对色相

一条曲线只有在至少含两个点时才生效。整个对象留空（或只含单点曲线）时，节点为直通。

### sat_thrsh
饱和度阈值，默认 0.0，范围 0.0…1.0。按像素本身的饱和程度对校正做门控，使接近灰的像素受影响更小 —— 这能防止色相调整渗入中性区域。

### luminance_mix
默认 0.0，范围 0.0…1.0。混入一个按明度加权的响应，使校正尊重亮度，从而弱化其对极暗或极亮像素的作用。

## 输出

| 输出 | 类型 | 含义 |
|---|---|---|
| **video** | `COMFYTV_VIDEO` | 色相校正后的片段快照 |

## 提示

- 每条曲线需要两个及以上的点才会生效；孤立的单点不起作用。
- 当色相调整渗入灰/中性区域时，提高 `sat_thrsh`。
- 这是用于定向色相处理的 —— 若要做全局色相/饱和度调整，请改用 **Video Color**。

## 相关节点

- **Selective Color** —— 用滑块微调固定的色族（红、青、中性色……）
- **Video Color** —— 一步搞定全局色相与饱和度
- **Video Curves** —— 逐通道影调曲线，而非色相驱动曲线
