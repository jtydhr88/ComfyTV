## 这个节点做什么

本节点在 `COMFYTV_VIDEO` 素材上合成一个合成镜头光晕：在选定位置的中心辉光、可选的水平变形条纹，以及一串横穿画面的「鬼影」反射。它在 Torch 后端作为 fx-spec 处理；当 `intensity` 为 0 时原样透传。

它带有 ▶ Run。输入与输出都是 `COMFYTV_VIDEO`。要把结果交给原生 ComfyUI 节点，请插入 **Bridge**——见[桥接说明](https://github.com/jtydhr88/ComfyTV/blob/main/docs/bridges.md)。

## 何时使用

- 添加一个指向太阳/实景光源的光晕，营造电影或科幻感。
- 强化主镜头或由镜头驱动的转场。
- 伪造原素材缺失的光源反应。

## 参数

### pos_x / pos_y
光晕亮源所在位置，各自在画面上范围 0.0 到 1.0（默认 `pos_x` 0.75、`pos_y` 0.25——右上）。鬼影链从这一点经画面中心延伸。

### intensity
光晕整体亮度，范围 0.0 到 3.0（默认 0.8）。0 完全关闭效果。

### size
中心辉光的大小，范围 0.05 到 1.0（默认 0.25），以画面比例表示。

### streak
穿过光晕中心的水平变形条纹强度，范围 0.0 到 1.0（默认 0.5）。设为 0 得到没有条纹的圆形光晕。

### ghosts
沿光晕轴向的次级鬼影反射数量，整数 0 到 8（默认 5）。鬼影越多，镜头反射链越繁忙；0 只保留辉光和条纹。

## 输出

| 输出 | 类型 | 含义 |
|---|---|---|
| **video** | `COMFYTV_VIDEO` | 叠加了光晕的素材 |

## 提示

- 把 `pos_x/pos_y` 放在镜头中最亮的光源上，使光晕看起来有出处。
- 降低 `streak` 和 `ghosts` 得到含蓄辉光；两者都提高得到风格化、明显的光晕。
- 在明亮背景上让 `intensity` 保持适中，以免光晕把整个画面曝爆。
