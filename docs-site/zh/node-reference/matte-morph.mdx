## 这个节点做什么

Matte Morphology（遮罩形态学）用形态学运算重塑遮罩。腐蚀（erode）把遮罩边缘向内收（缩小），膨胀（dilate）把它向外推（扩大），开/闭是用于清理噪点的组合运算：开运算（先腐蚀后膨胀）去除小的杂散斑点，闭运算（先膨胀后腐蚀）填补小孔洞。你可以在水平和垂直方向分别控制幅度。

输入与输出都是 `COMFYTV_VIDEO`。它作为实时 fx 预览滤镜运行（输出一个 fx spec 并直通），因此无需完整渲染即可预览重塑后的遮罩。

## 何时使用

- 抠像在主体周围留下一圈背景边缘 —— 腐蚀一两像素把它修掉。
- 遮罩有孔洞或斑点 —— 用闭/开运算清理。
- 在用 **Key Mix** 合成前，你需要收缩或扩张遮罩。

## 参数

### op
形态学运算：`erode`（默认，收缩）、`dilate`（扩大）、`open`（去除小斑点）或 `close`（填补小孔洞）。

### size_x
运算的水平尺寸，单位像素。范围 `0`–`64`，默认 `1`。0 表示该轴无效果。

### size_y
运算的垂直尺寸，单位像素。范围 `0`–`64`，默认 `1`。0 表示该轴无效果。

## 输出

| 输出 | 类型 | 含义 |
|---|---|---|
| **video** | `COMFYTV_VIDEO` | 重塑后的遮罩。 |

## 提示

- 先用尺寸 1–2 的 `erode` 修掉薄薄的背景光晕；超过几像素就会开始吃掉真实边缘。
- 用 `close` 封住主体上的针孔，用 `open` 去掉孤立的噪点。
- 当遮罩问题有方向性时（如水平运动模糊），分别设置 `size_x` 与 `size_y`。
- 要与原生 ComfyUI 节点互通，请插入 **Bridge**。见 [bridges.md](https://github.com/jtydhr88/ComfyTV/blob/main/docs/bridges.md)。
