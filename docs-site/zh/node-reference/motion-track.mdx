## 这个节点是做什么的

**Motion Track（运动跟踪）** 跟踪片段里的一个或多个点。你在节点的视频预览上直接点击落点；点 ▶ 运行后，它逐帧做模板匹配，把跟踪路径作为文本数据返回。可选地，它还能从这些点解算出一个运动变换（平移、相似或透视四角），让下游节点能钉位、稳定或做四角定位。

与其它蒙版节点不同，它的输出是 `COMFYTV_TEXT`（JSON 形式的跟踪数据），不是视频。视频输入是 `COMFYTV_VIDEO`。要把跟踪文本用于 ComfyUI 原生节点，通过 `ComfyTV/Bridge` 桥接——详见 https://github.com/jtydhr88/ComfyTV/blob/main/docs/bridges.md。

## 节点上的编辑器

卡片在视频上叠一层画布：

- 在空白处 **单击** 添加一个跟踪点（一个绿色十字加编号的模板框）。
- **双击** 某点删除它。
- **第一个点** 还会显示一个黄色虚线的 **search（搜索）** 框。
- 覆盖层为每个点画出 **pattern（模板）** 框（被匹配的模板），并为 1 号点画出 **search** 框（每帧的搜寻范围）。
- **Clear（清除）** 动作删除所有点。

运行前必须至少放一个点，否则节点会报「click at least one point on the node first」。

## 参数

### points
点击的跟踪点，存为 JSON `[{x,y},...]`。由节点上的编辑器在你点击时写入。默认空。（若 `points` 为空但设了 `point_x`/`point_y`，则用单个点。）

### point_x / point_y
第一个点的坐标，`0`–`8192`，默认 `0`。它们镜像编辑器里的 1 号点。

### solve
从跟踪点拟合何种变换。可选：`none`、`translation`、`similarity`、`perspective`。默认 `none`。`similarity` 需要 2 个以上点，喂给 Transform/Composite；`perspective` 需要 4 个以上点，喂给 Corner Pin；`none` 只返回原始轨迹。

### t_start / t_end
跟踪的时间窗口（秒）。`t_start` 范围 `0`–`3600`，默认 `0`；`t_end` 默认 `-1`（表示到片尾），范围 `-1`–`3600`，步进 `0.05`。

### pattern
模板半尺寸（像素）——每帧匹配的模板框。范围 `4`–`64`，默认 `12`。模板越大越有辨识度，但越慢，也越不容忍形变。

### search
搜索半径（像素）——跟踪器每帧寻找模板的范围。范围 `8`–`128`，默认 `24`。运动快就调大。

## 输出

| 输出 | 类型 | 含义 |
|---|---|---|
| **track** | `COMFYTV_TEXT` | JSON 跟踪数据：各点路径带置信度，以及（若解算）一个 `transform` 关键帧列表或透视的 `corners` |

## 小贴士

- 选高对比、不重复的特征来跟踪；平坦或重复的区域会抖动（看结果里的置信度）。
- 让 `search` 匹配运动速度——太小会跟丢快速运动，太大则变慢且可能锁到错误特征。
- 做 `perspective` 四角定位时，把点放在平面的四个角上。
