扩散模型画不了密集或双语文字。这个节点做分工：AI 在上游生成视觉素材，Poster 节点用真排版摆放标题、正文、形状和图片框。实时预览里看到的，就是 Run 渲染出来的。

## 输入

| 输入 | 类型 | 说明 |
|---|---|---|
| `images` | 图像（自动扩展） | 接入一张图后自动出现下一个槽位。海报元素按槽位号取图；在卡片上双击图片框可改选它显示哪张接入图。 |

## 卡片控件

- **模板** —— 版式预设（Hero 主视觉 / Sidebar 图文栏 / Infographic 信息图）。所有模板的所有元素都能拖拽、缩放、编辑。
- **尺寸预设** —— A4 / A3 / 方形 / 9:16 竖屏 / 16:9 宽屏 / 2:3 海报。改尺寸时设计按比例重排（位置归一化存储，字号随高度缩放）。
- **配色** —— 主色 / 强调色 / 背景色三个取色器。元素引用这些色彩记号，改一处即全局换装。
- **字体** —— 标题、正文两个字体下拉框，来自[资源库](/guides/sidebar)的字体收藏。字体会嵌入渲染结果，任何机器上效果一致。
- **✎ 布局** —— 开关拖拽编辑器：在实时预览上移动、八向缩放任意元素，自动吸附其它元素与画布的边和中线（按住 `Alt` 临时关闭）。`Delete` 删除选中元素。
- **多选** —— `Shift` 点选增删元素，或在空白处拖出框选。选中 2 个以上可整组拖动，并出现**对齐与分布**工具条：左/中/右、上/中/下对齐，外加中心均布与等间距分布（3 个以上可用）。
- **旋转** —— 单选元素时框上方出现圆形手柄，拖动即旋转（`Shift` = 15° 步进）。已旋转的元素仍可自由移动和再旋转；转回 0° 后缩放手柄恢复。
- **参考线与网格** —— `┊+` / `┄+` 放置竖/横参考线（拖动摆放，拖出画布删除）；`⌗` 开关 12 列网格。两者都是吸附目标，且不会出现在渲染结果里。
- **等距吸附** —— 在两个邻居之间（或沿一排等距元素）拖动时，会吸附到让间距相等的位置，并显示间距标记。
- **➕ 添加** —— 添加文本、图片或形状元素。
- 双击**文本**元素就地编辑内容；双击**图片**元素挑选图源槽位；双击**形状**元素切换 矩形/椭圆/线条 及填充、描边记号。
- 选中**文本**元素出现小工具条：标题/正文字体、字号、对齐、颜色记号。选中**图片**元素有 ✥ 平移 + 缩放滑块，在框内取景。

## 输出

| 输出 | 类型 | 说明 |
|---|---|---|
| `image` | 图像 | 渲染完成的海报（PNG）。 |

## 说明

- 定位文本会自动缩字号（最小约 8px），内容超框时不会被悄悄裁掉。
- 实时预览完全在浏览器里跑。Run 时用无头 Chromium 渲染同一份 HTML，需要在 ComfyUI 环境里一次性安装：`pip install playwright`，再 `playwright install chromium`。没装之前预览照常，Run 会提示缺依赖。
- 想加自己的版式，把模板文件夹放进 `nodes/poster/templates/<name>/`（`template.html` + `meta.json`）即可。
