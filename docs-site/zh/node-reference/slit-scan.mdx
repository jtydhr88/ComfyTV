## 这个节点做什么

**狭缝扫描 (Slit Scan)** 用视频里不同时间点重建每一帧输出：画面的一条带读取「过去」，另一条读取「未来」，于是运动在画面中滴淌、拉伸。它在 **▶ Run** 时运行并写出新的 `COMFYTV_VIDEO` 快照。

偏移可以**横向 (horizontal)** 扫、**纵向 (vertical)** 扫，或跟随你提供的灰度**映射 (map)** 图像（暗 = 一个时刻，亮 = 另一个时刻）。往 **retime_image** 接入一张图像会自动把节点切换到 `map` 模式。

输入与输出是 `COMFYTV_VIDEO`；可选的映射图是 `COMFYTV_IMAGE`。若要对接原生 ComfyUI 节点，请插入 **Bridge**——见[桥接指南](https://github.com/jtydhr88/ComfyTV/blob/main/docs/bridges.md)。

## 何时使用

- 对运动主体做标志性的「时间切片」／涂抹效果。
- 制作运动瀑布，让画面上下相差数秒。
- 用灰度映射（例如渐变或形状）驱动自定义的重定时图案。

## 参数

### mode
逐像素时间偏移的布局方式。选项：`horizontal`、`vertical`、`map`。默认 `horizontal`。若接入了 **retime_image**，节点强制 `map` 模式；若选了 `map` 却没接图像，Run 会报错并要求提供映射。

### gain
时间展开强度，`-120`–`120`（步长 `1`），默认 `24.0`。幅度越大，画面的行／列在时间上拉得越开；负值翻转哪一端是「过去」。

### offset
基线时间偏移，`-60`–`60`（步长 `0.5`），默认 `0.0`。把整个狭缝窗口整体前移或后移。

### filter_mode
中间时刻如何采样。选项：`nearest`（吸附到最近帧——更锐、更块状）或 `linear`（帧间混合——更平滑）。默认 `linear`。

### invert
翻转时间梯度方向（交换过去/未来两端，或反转映射读取）。默认关闭。

### retime_image（可选，`COMFYTV_IMAGE`）
为每个像素指定时间偏移的灰度映射。接入它会自动切到 `map` 模式。当 **mode** 为 `map` 时必需。

## 输出

| 输出 | 类型 | 含义 |
|---|---|---|
| **video** | `COMFYTV_VIDEO` | 狭缝扫描后的片段，作为新的项目快照 |

## 提示

- 效果只在有运动处显现——静止镜头几乎不变。
- 想要平滑涂抹用 `linear` 的 **filter_mode**，想要更锐、阶梯状的时间切片用 `nearest`。
- 使用 **map** 模式时，请提供干净的灰度图像；其亮度决定每个像素的时刻，因此渐变给出扫掠式涂抹、形状给出局部涂抹。
