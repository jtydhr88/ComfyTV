## 这个节点做什么

时间重映射 (Time Remap) 改变单个 `COMFYTV_VIDEO` 的*时序*，而不仅是恒定倍速。在 **speed** 模式下，你编写速度关键帧（相对输出时间的速度倍率），让片段在慢动作与快动作之间渐变。在 **hold** 模式下，它停在选定的一帧上，可选每个输出帧按小步进推进，产生步进/顿帧效果。

它在 **▶ Run** 时运行。输入与输出均为 `COMFYTV_VIDEO`。在 `speed` 模式下若未设定速度关键帧，节点会报错——纯粹的恒定倍速请改用 Video Speed。

要把结果交给原生 ComfyUI 节点，请插入 **Bridge**（`ComfyTV/Bridge`）。参见 https://github.com/jtydhr88/ComfyTV/blob/main/docs/bridges.md。

## 何时使用

- 对镜头做速度渐变：缓入慢动作，再甩回全速。
- 在关键瞬间保持一个定格。
- 用带小步进的 hold 制造步进/顿帧观感。

## 参数

### mode
`speed`（由关键帧驱动的变速重定时）或 `hold`（停在某一帧）。默认 `speed`。

### speed_keys
仅 `speed` 模式。JSON 数组 `[{t (输出秒), v (速度 ×), interp}]`——相对输出时间的速度倍率。经由节点的曲线 UI 编写。`speed` 模式下必填。

### smooth_fps
仅 `speed` 模式。整数 `0`–`120`，默认 `0`。`0` = 关闭；大于 0 时先把源预插值到该帧率再重定时，让慢动作更平滑（渲染更慢）。

### hold_frame
仅 `hold` 模式。整数 `0`–`100000`，默认 `0`。要定格的源帧索引。

### hold_increment
仅 `hold` 模式。整数 `0`–`1000`，默认 `0`。每个输出帧推进多少源帧；`0` 为真正定格，小值给出步进/顿帧运动。

### video（输入，可选）
要重定时的 `COMFYTV_VIDEO`。必填。

## 输出

| 输出 | 类型 | 含义 |
|---|---|---|
| **video** | `COMFYTV_VIDEO` | 重定时（或定格）后的片段。 |

## 提示

- 单一固定倍速（例如始终 2×）请使用 Video Speed——时间重映射专用于*变化*的速度，无关键帧会报错。
- `smooth_fps` 有助于让极慢的渐变更流畅，但它会先插值源、明显更慢；除非看到抖动，否则保持 0。
