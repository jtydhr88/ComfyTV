## 这个节点是做什么的

**Video Speed** 按 **speed** 倍率对片段变速，还能 **reverse**（倒放）。这是服务端的真实重新编码
（PyAV / ffmpeg），因此在 **▶ 运行**时执行，并把结果保存为项目快照。输入输出均为 `COMFYTV_VIDEO`。

如果 **speed** 保持 1x 且未开启 **reverse**，就无事可做，运行会报错——请改变速度或打开倒放。

## 适用场景

- 对某一瞬间做慢动作强调，或做快进蒙太奇。
- 把片段倒放，做倒带或循环效果。
- 微调片段时长，以贴合音乐节拍或目标长度。

## 参数说明

### speed（速度）
播放速率倍数。范围 **0.1–10.0**，默认 **1.0**，步进 0.05。大于 1.0 更快（片段变短）；
小于 1.0 更慢（片段变长）。2.0 = 两倍速，0.5 = 半速。

### reverse（倒放）
把片段倒着播放。默认**关**。可与变速组合使用。

### pitch_compensate（音调补偿）
默认**开**。开启时，音频会做时间伸缩，让人声/音乐保持原本音调，而不会因加速变成尖细的
「花栗鼠」声、或因减速变得低沉。若你想要随速度变化的老式磁带式变调，则关闭它。

## 输出说明

| 输出 | 类型 | 含义 |
|---|---|---|
| **video** | `COMFYTV_VIDEO` | 变速（可选倒放）后的片段，保存为快照。 |

## 小贴士

- speed = 1x 且倒放关闭时什么都不做并会报错——请设置其一。
- 极端慢放（speed 很小）不会合成新的中间帧，而是拉伸已有帧。若需顺滑，请先用专门的插帧节点。

## Bridge 说明

`COMFYTV_VIDEO` 是项目快照引用，不是 ComfyUI 原生张量。要在 ComfyTV 与原生 ComfyUI 节点之间互通，
请插入 **Bridge**（`ComfyTV/Bridge`）。详见
https://github.com/jtydhr88/ComfyTV/blob/main/docs/bridges.md。
