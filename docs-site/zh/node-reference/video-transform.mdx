## 这个节点做什么

视频变换 (Video Transform) 对单个 `COMFYTV_VIDEO` 施加 2D 几何变换：平移、等比缩放、旋转和水平斜切。它可以用关键帧让变换产生动画，并加入基于快门的运动模糊，让快速运动自然拖尾。

本节点是 FX 链的一环。若变换为恒等（无位移、缩放为 1、无旋转/斜切、无关键帧），它会原样透传片段。否则，当它接入链路时会输出一个 FX spec，与链路其余部分一趟渲染完成；当连接了 **track** 输入时，它会烘焙并通过 **▶ Run** 单独渲染。输出为 `COMFYTV_VIDEO`。

要把结果交给原生 ComfyUI 节点，请插入 **Bridge**（`ComfyTV/Bridge`）。参见 https://github.com/jtydhr88/ComfyTV/blob/main/docs/bridges.md。

## 何时使用

- 重新构图、调整尺寸或摆正镜头。
- 用关键帧做推近/拉远或甩镜。
- 通过 `track` 输入施加跟踪出的变换，把某一层贴到运动上。

## 参数

### pos_x / pos_y
平移，单位像素。范围 `-8192`–`8192`，步长 `1`，默认 `0`。正 `pos_x` 向右，正 `pos_y` 向下。

### scale
等比缩放，`0.01`–`10.0`，默认 `1.0`（100%）。

### rotation
旋转，单位度，`-360`–`360`，步长 `0.5`，默认 `0`。

### skew_x
水平斜切（错切），`-2.0`–`2.0`，默认 `0.0`。

### motion_blur
运动模糊强度，`0.0`–`4.0`，默认 `0.0`。`0` = 关闭；数值越大，在运动过程中取的快门采样越多，拖尾越平滑。

### shutter
运动模糊的快门角度/开启时长，`0.0`–`4.0`，步长 `0.05`，默认 `0.5`。越大拖尾越长。

### shutter_type
快门相对每帧的开启位置：`centered`、`start`、`end` 或 `custom`。默认 `centered`。

### shutter_offset
额外的快门相位偏移（配合 `shutter_type` = `custom` 使用），`-4.0`–`4.0`，步长 `0.05`，默认 `0.0`。

### keyframes
高级项：JSON 数组 `[{t, x, y, scale, rotation, interp}]`，为变换生成动画。通常经由节点的关键帧 UI 设置。

### video（输入，可选）
要变换的 `COMFYTV_VIDEO`。

### track（输入，可选）
一个 `COMFYTV_TEXT` 运动轨道。连接后，其关键帧驱动变换，且节点会直接渲染（烘焙片段），而不是向链路下游传递 FX spec。

## 输出

| 输出 | 类型 | 含义 |
|---|---|---|
| **video** | `COMFYTV_VIDEO` | 变换后的片段。 |

## 提示

- 无变换且无关键帧时，节点为透传——它什么都不做，这是预期行为。
- 只有当变换确实在运动时（关键帧或轨道）运动模糊才有意义；静态变换没有可拖尾的对象。

## 相关节点

- **Video Composite** — 相同的变换，但把前景合并到背景上。
- **Corner Pin** — 自由的四角扭曲，而非平移/缩放/旋转。
- **UV Remap** — 由 UV 图驱动的任意逐像素扭曲。
