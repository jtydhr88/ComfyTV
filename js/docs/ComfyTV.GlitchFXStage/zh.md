# 故障特效 (Glitch FX)

> Datamosh 风格的数字故障——块位移与 RGB 通道分离，一次 ▶ Run 完成。

## 这个节点做什么

**故障特效 (Glitch FX)** 故意用水平块位移和色差（RGB）通道偏移来「损坏」一段 `COMFYTV_VIDEO`，并在 **▶ Run** 时写出新快照。损坏由 **seed** 逐帧随机生成，因此结果可复现。

输入与输出都是 `COMFYTV_VIDEO`。若要对接原生 ComfyUI 节点，请插入 **Bridge**——见[桥接指南](https://github.com/jtydhr88/ComfyTV/blob/main/docs/bridges.md)。

## 何时使用

- 为转场或点缀伪造信号损坏／断线传输的外观。
- 给音乐视频或标题卡加上 VHS／datamosh 的粗粝质感。
- 用偶发的撕裂帧闪烁（低 **chance**）配合鼓点强化节奏。

## 参数

### chance
某一帧被故障化的概率，`0.0`–`1.0`，默认 `0.5`。为 `0` 时节点原样透传片段（恒等）。调低得到稀疏、点睛式的故障；`1.0` 则每帧都故障。

### block_h
故障块高度，占画面的比例，`0.01`–`1.0`，默认 `0.2`。越小是细窄的撕裂条；越大是大块位移条带。

### shift
水平位移量，`0.01`–`1.0`，默认 `0.2`。故障块横向滑移的距离。

### color_intensity
RGB 通道分离强度，`0`–`4`，默认 `3`。`0` = 无色差分离；越高把红/绿/蓝通道拉得越开。

### seed
随机种子，`0`–`99999`，默认 `7`。相同种子 = 相同故障图案；改动它可重掷。

## 输出

| 输出 | 类型 | 含义 |
|---|---|---|
| **video** | `COMFYTV_VIDEO` | 故障化后的片段，作为新的项目快照 |

## 提示

- 将 **chance** 设为 `0` 即可在不拔线的情况下与未处理片段做 A/B 对比。
- **chance** 低、**shift** 高得到稀疏但猛烈的冲击；**chance** 高、**shift** 低得到持续的微颤。

## 相关节点

- **频闪 (Strobe)** — 按间隔闪烁/保持帧，另一种冲击方式。
- **艺术特效 (Art FX)** — 风格化外观，而非数字损坏。
