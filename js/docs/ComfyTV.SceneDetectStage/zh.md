# 场景检测 (Scene Detect)

> 找出视频中的切镜点，并把它拆成每个镜头的缩略图或可直接使用的片段。

## 这个节点是做什么的

**Scene Detect（场景检测）** 分析 `COMFYTV_VIDEO`，找出场景切换点，然后返回每个镜头一张缩略图，或每个镜头一段裁好的片段。你设定检测阈值和最小间隔、选 **output** 模式，然后点 **▶ 运行**（服务器端一次 ffmpeg/分析处理）。卡片显示检测到的缩略图；在 **clips** 模式下还有可滚动的片段池，点击即可挑选一段。

在 **clips** 模式下，节点还会根据 **selected_index** 输出被选中的片段，且片段结果会缓存（最多 8 组近期设置），因此重新挑另一段很快。若未找到切点会报错，提示降低阈值。

## 适用场景

- 把一条长镜头或录屏拆成一个个镜头。
- 为故事板或审片宫格每个场景取一张代表帧。
- 自动把素材切成片段，挑出想继续编辑的那段。

## 参数说明

### threshold（阈值）
切点检测灵敏度，0.05–1.0，默认 0.4。越低越灵敏（切点更多）；切得太碎就调高。

### min_gap_s（最小间隔）
两个切点之间的最小秒数，0–30，默认 1.0。避免在闪烁或快速运动时连切两刀。

### output（输出模式）
`frames`（默认）返回每镜头一张缩略图；`clips` 返回每镜头一段裁好的片段（并启用片段挑选）。

### cut_mode（裁切方式）
仅 **clips** 模式使用：`fast`（默认）或 `precise`。`fast` 在关键帧处裁切（更快）；`precise` 重编码以获得精确边界。

### selected_index（选中序号）
**clips** 模式下 **clips** 输出对应第几段片段（从 1 起）。也可通过点击卡片中的片段驱动。会被限制在片段数量范围内。

## 输入与输出

| 接口 | 类型 | 含义 |
|---|---|---|
| **video**（输入） | `COMFYTV_VIDEO` | 要分析的片段（必填） |
| **images**（输出） | `COMFYTV_IMAGES` | 每镜头一张缩略图（首帧 + 每个切点） |
| **clips**（输出） | `COMFYTV_VIDEO` | 被选中的单镜头片段（clips 模式） |

## 使用提示

- 阈值从 0.4 起；漏掉硬切就调低；平移/推拉误触发就调高 `min_gap_s`。
- 快速审片用 `fast`；只有需要帧级精确边界时才切到 `precise`。
- 片段结果按（源、阈值、间隔、cut_mode）缓存——点看不同片段不会重跑检测。

## 类型与 Bridge

`COMFYTV_VIDEO` / `COMFYTV_IMAGES` 是 ComfyTV 项目快照，不是 ComfyUI 原生类型。用 **Bridge**（`ComfyTV/Bridge`）与原生节点互通。详见 [bridges.md](https://github.com/jtydhr88/ComfyTV/blob/main/docs/bridges.md)。
