# 抽取多帧 (Extract Frames)

> 在你标记的时间点从片段抓取静止帧，并以图像批量的形式取回。

## 这个节点是做什么的

**Extract Frames** 会在你用节点体内标记条设定的时间戳处，从片段中抽出一张或多张静止帧。点 **▶ 运行**后，
服务端（PyAV / ffmpeg）解码这些帧，并作为 `COMFYTV_IMAGES` 批量返回、保存为项目快照。输入为 `COMFYTV_VIDEO`。

标记条驱动一个隐藏的 **marks** 字段（一个以秒为单位的 JSON 列表）——你不用手动输入列表。至少需要一个标记，
后端会对批量大小设上限（每次运行最多几十帧）。

## 适用场景

- 从片段抓取关键静帧，用作参考图或缩略图。
- 抓首帧/尾帧/中间帧，作为图像生成或编辑步骤的起点。
- 从一个镜头采样多个瞬间，对比构图。

## 参数说明

### marks（标记，隐藏）
一个以秒为单位的时间戳 JSON 列表，每帧一个。由节点体内的标记条驱动——请在片段预览上添加标记，而不要编辑文本。
重复和负数时间会被清理；若未设置任何有效标记，运行会报错。

## 输出说明

| 输出 | 类型 | 含义 |
|---|---|---|
| **images** | `COMFYTV_IMAGES` | 抽出的帧构成的图像批量，保存为快照。 |

## 小贴士

- 这是多帧工具；若只要单帧且想用首/尾/中间预设，请改用 **Extract Frame**。
- 单次运行可抽取的帧数有上限——请标记你真正需要的瞬间，而非密集采样。

## Bridge 说明

`COMFYTV_VIDEO` 与 `COMFYTV_IMAGES` 都是项目快照引用，不是 ComfyUI 原生张量。要在 ComfyTV 与原生 ComfyUI
节点之间互通，请插入 **Bridge**（`ComfyTV/Bridge`）。详见
<https://github.com/jtydhr88/ComfyTV/blob/main/docs/bridges.md>。

## 相关节点

- **Extract Frame**——抓取单帧（首/尾/中间/自定义时间）。
- **Image Picker**——从抽出的批量里选一张图。
