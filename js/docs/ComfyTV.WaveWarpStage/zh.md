# 波形扭曲 (Wave Warp)

> 用行进的正弦波使画面产生涟漪，得到水面／热浪般的扭曲，一次 ▶ Run 完成。

## 这个节点做什么

**波形扭曲 (Wave Warp)** 沿一条随时间行进的正弦波位移 `COMFYTV_VIDEO` 的像素，并在 **▶ Run** 时写出新快照。波形可横向、纵向或双向行进，其强度还能用包络在画面上渐变。

输入与输出都是 `COMFYTV_VIDEO`。若要对接原生 ComfyUI 节点，请插入 **Bridge**——见[桥接指南](https://github.com/jtydhr88/ComfyTV/blob/main/docs/bridges.md)。

## 何时使用

- 添加水面倒影、热浪闪烁或水下摇摆。
- 让标题或图形做轻柔的涟漪动态。
- 为转场或闪回营造梦幻、不稳定的观感。

## 参数

### amplitude
位移强度（像素），`0.0`–`200.0`（步长 `1`），默认 `16.0`。为 `0` 时节点原样透传片段。越高波形越大、越明显。

### frequency
画面上容纳的波形周期数，`0.1`–`40.0`（步长 `0.1`），默认 `3.0`。越高涟漪越密。

### speed
波形随时间行进的速度，`-8.0`–`8.0`（步长 `0.05`），默认 `0.5`。负值反向；`0` 冻结波形。

### axis
波形位移的方向。选项：`both`、`horizontal`、`vertical`。默认 `both`。

### envelope
振幅在画面上如何渐变。选项：`parabolic`（中间最强、边缘渐弱）或 `uniform`（处处均匀）。默认 `parabolic`。

## 输出

| 输出 | 类型 | 含义 |
|---|---|---|
| **video** | `COMFYTV_VIDEO` | 扭曲后的片段，作为新的项目快照 |

## 提示

- 将 **amplitude** 设为 `0` 即可在不拔线的情况下旁路该效果。
- 小 **amplitude** + 高 **frequency** 读作热浪闪烁；大 **amplitude** + 低 **frequency** 读作缓慢的水面涌动。

## 相关节点

- **水面 (Water)** — 物理驱动的涟漪（雨滴／漩涡），而非固定正弦波。
- **万花筒 (Kaleidoscope)** — 镜像画面得到对称扭曲。
