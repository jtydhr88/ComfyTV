# 色差 (Chromatic Aberration)

> 以某个中心点为基准把红/绿/蓝通道向外错开，制造「廉价镜头」的彩色边缘——或调成负值把边缘拉回。

## 这个节点做什么

本节点围绕一个中心点径向偏移各颜色通道，模拟真实镜头无法把所有波长聚焦到同一点的现象。效果向画面边缘逐渐增强，因此中心保持干净、四角出现彩边。它在 Torch 后端作为 fx-spec 处理；当 `amount` 为 0 时不做任何处理（透传）。

它带有 ▶ Run。输入与输出都是 `COMFYTV_VIDEO`。要把结果交给原生 ComfyUI 节点，请插入 **Bridge**——见[桥接说明](https://github.com/jtydhr88/ComfyTV/blob/main/docs/bridges.md)。

## 何时使用

- 给过于干净的 CG 或 AI 生成素材添加可信的镜头质感。
- 与颗粒和暗角一起营造复古/低保真外观。
- 匹配一个本身已有可见彩色边缘的底板。

## 参数

### amount
通道错开的强度与方向，范围 -0.05 到 0.05（默认 0.01，步长 0.001）。正值把通道推开（经典彩边）；负值向另一方向拉。0 表示无效果。

### falloff
效果从中心到边缘增强的快慢，范围 0.5 到 3.0（默认 1.0）。值越高中心越干净、彩边越集中于最角落；值越低分布越均匀。

### center_x / center_y
错开所辐射的中心点，各自范围 -0.5 到 0.5（默认 0 = 画面中心），以画面比例表示。若「干净」点应偏离中心就偏移它。

## 输出

| 输出 | 类型 | 含义 |
|---|---|---|
| **video** | `COMFYTV_VIDEO` | 施加通道彩边后的素材 |

## 提示

- `amount` 保持小值——接近 ±0.01 就已明显；整个 ±0.05 是极端值。
- 搭配轻微暗角和颗粒可获得可信的老镜头质感。
- 移动 `center_x/center_y` 以匹配你真实或预期镜头最锐利点的位置。

## 相关节点

- **Lens Distort** — 镜头质感的几何方面（桶形/枕形）。
- **Lens Flare** — 同一套复古/主镜头工具中的另一种镜头伪影。
