# Despill（去溢色）

> 去掉渗到主体上的绿幕或蓝幕颜色，同时完全不动抠像本身。

## 这个节点做什么

Despill（去溢色）会去除色度抠像之后（或独立于抠像）反射到发丝、皮肤和边缘上的残余幕布色调（绿色或蓝色溢色）。它借助相邻通道重新平衡出问题的通道，并可选择输出它算出的溢色图，而非校正后的图像，让你看清它到底在修什么。

输入与输出都是 `COMFYTV_VIDEO`。此节点作为实时 fx 预览滤镜运行（输出一个 fx spec 并直通），因此无需完整渲染即可看到结果。

## 何时使用

- 抠像后主体边缘发绿/发蓝。
- 你想在抠像前先清溢色，让抠像本身更轻松。
- 你想用溢色图输出查看溢色分布位置。

## 参数

### screen
要去除的溢色颜色：`green`（默认）或 `blue`。

### spill_mix
校正的施加强度。范围 `0.0`–`1.0`，默认 `0.5`。仍有边缘残色就调高；主体发灰就调低。

### expand
向外扩大受影响区域，捕捉边缘之外的溢色。范围 `0.0`–`1.0`，默认 `0.0`。

### red_scale / green_scale / blue_scale
重建被抑制颜色时使用的逐通道缩放。各范围 `-2.0`–`2.0`。默认：`red_scale` 为 `0.0`，`green_scale` 为 `-1.0`，`blue_scale` 为 `0.0`。它们偏置如何用其他通道替换幕布通道；默认值适合绿色溢色。

### brightness
调整校正后像素的亮度，以补偿被去除的颜色。范围 `-1.0`–`1.0`，默认 `0.0`。

### output_spillmap
开启时输出算出的溢色图（溢色位置与强度的可视化），而非去溢色后的图像。默认关闭。用它来调其他控件，调好后再关闭。

## 输出

| 输出 | 类型 | 含义 |
|---|---|---|
| **video** | `COMFYTV_VIDEO` | 去溢色后的片段；`output_spillmap` 开启时为溢色图。 |

## 提示

- 去溢色不产生透明 —— 它只修颜色。请搭配抠像器来获得真正的遮罩。
- 调 `spill_mix`/`expand` 时先开 `output_spillmap`，调好后关闭以渲染干净结果。
- 要与原生 ComfyUI 节点互通，请插入 **Bridge**。见 [bridges.md](https://github.com/jtydhr88/ComfyTV/blob/main/docs/bridges.md)。

## 相关节点

- **Chroma Key** / **Keyer** / **PIK Keyer** —— 产生遮罩、与 Despill 互补的抠像器。
- **Color Suppress** —— 抑制六种原色/次色中的任意一种，不限于幕布溢色。
