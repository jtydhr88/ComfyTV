# 序列 (Sequence)

> 把多段片段首尾相接组装成一条剪辑，支持每段的入/出点裁切和可选转场。

## 这个节点做什么

序列 (Sequence) 是一个迷你的剪辑组装节点。把最多十二段 `COMFYTV_VIDEO` 片段接到它自增长的 **videos** 输入，然后用节点上的段列表把它们排成播放顺序。每个片段可携带入点、出点、转场类型和转场时长；节点按该顺序把它们拼接成一段片段。

如果你不定义任何片段，序列 (Sequence) 就直接按槽位顺序把已连接的片段用硬切串起来。它在 **▶ Run** 时运行（渲染组装出的序列），至少需要一段已连接的片段。输出为单个 `COMFYTV_VIDEO`。

要把结果交给原生 ComfyUI 节点，请插入 **Bridge**（`ComfyTV/Bridge`）。参见 <https://github.com/jtydhr88/ComfyTV/blob/main/docs/bridges.md>。

## 何时使用

- 不离开 ComfyTV，用若干镜头搭出一条粗剪。
- 裁切每段片段的入/出点，并在选定切点间加入淡入或划像。
- 把多个渲染通道或多条 take 拼接成一个连续文件。

## 参数

### segments
JSON `[{slot, in_s, out_s, transition, trans_dur}]`，按播放顺序描述：哪个槽位播放、其入/出裁切点（秒）、进入它的转场及其时长。由节点上的段列表 UI 驱动，而非手动输入。留空则仅用硬切把所有已连接片段拼接起来。

### videos（输入）
自增长的一组 `COMFYTV_VIDEO` 槽位（`video0`、`video1`……），最多 12 个。每个槽位接一段片段；`segments` 列表按槽名引用它们。

## 输出

| 输出 | 类型 | 含义 |
|---|---|---|
| **video** | `COMFYTV_VIDEO` | 组装出的序列（所有选定片段按顺序拼接）。 |

## 提示

- `segments` 列表为空时，你会得到所有已连接槽位按顺序、用硬切的纯拼接——一种快速连接片段的方式。
- 段列表按名称引用槽位，因此把中间某个槽位留空只意味着不包含该槽位，不会移动其他槽位。

## 相关节点

- **Video Transition** — 恰好两段片段间的单个交叉淡化/转场。
- **Luma Wipe** — 两段片段间由图案驱动的划像。
- **Time Remap** — 在放入序列之前对单段片段变速。
